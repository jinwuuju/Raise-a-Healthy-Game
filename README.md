# 메디컬 퀘스트: 의학기자 키우기 — 웹 설계실

이 저장소는 게임 《메디컬 퀘스트: 의학기자 키우기》의 웹 설계실과 기획 원본을 관리하기 위한 저장소입니다.

> **2026-10-10 현재 상태:** 기존 작업 환경에서 제작한 웹 설계실 원본 파일과 상세 설계 문서 28개는 아직 이 저장소에 반영되지 않았습니다. 배포용 워크플로와 기본 검증 스크립트만 준비된 상태입니다. 기존 작업에서 보고된 ‘설계 일관성 802개’와 ‘링크·자산 143개’ 검사 결과는 이 저장소에서 다시 실행해 확인한 결과가 아닙니다.

## 디렉터리 규칙

- `site/` — 실제 공개할 웹 설계실 파일. 시작 파일은 반드시 `site/index.html`입니다. CSS, JavaScript, 이미지, 사용자에게 공개해도 되는 문서만 이 디렉터리에 넣습니다.
- `design/` — 게임 기획 및 상세 설계 원본을 관리하는 공간. **이 폴더는 GitHub Pages에 자동 게시되지 않지만, 저장소가 공개이므로 GitHub에서는 누구나 볼 수 있습니다.** 외부 공개하면 안 되는 내용은 이 저장소에 업로드하지 마세요.
- `scripts/check-site.mjs` — HTML의 상대 링크·자산과 JavaScript 구문을 확인합니다.
- `scripts/build.mjs` — 공개용 `site/` 파일만 `dist/`로 복사합니다.
- `.github/workflows/pages.yml` — `main`에 변경된 웹 파일이 반영되면 검증, 빌드, GitHub Pages 배포를 순서대로 수행합니다.

## 올리기 전에

1. 앞서 제작한 웹 설계실 원본 전체를 `site/`에 복사하고 `site/index.html`을 확인합니다.
2. 별도의 설계 문서는 공개 가능 여부를 검토한 후 `design/`에 올립니다. 사이트 내부에서 접근할 문서는 `site/` 아래에 포함해야 합니다.
3. GitHub 저장소 `Settings → Pages → Build and deployment → Source`를 **GitHub Actions**로 설정합니다.
4. `main`에 웹 파일이 반영되면 `Validate and deploy web design studio`가 실행됩니다. `Actions` 탭에서 검증·배포 결과를 확인합니다.

기본 검증은 앞서 완료된 802개·143개 검사를 대체하지 않습니다. 원래 사용한 검사 스크립트가 있으면 추가하여 배포 전에 함께 실행해야 합니다.
