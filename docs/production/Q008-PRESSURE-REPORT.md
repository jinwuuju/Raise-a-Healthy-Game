# Q008 하나의 숫자로 충분할까 · 고혈압 기초 (기본 과정)

2026-10-19 구현 · 2026-10-20 검증·배포 · D108 · 사용자: ‘이어서 진행’. D108 순서 ③. 설계 19의 **기본 과정 난이도 계약**(일반인 기준)으로 만든 두 번째 취재이며, 고혈압을 **기준 숫자 없이** 다룬다.

## 플레이와 범위

Q007 발행 → 편집장 의뢰(독자 편지: ‘병원에서 혈압을 한 번 쟀더니 높게 나왔어요. 그럼 저는 고혈압인가요?’, 혈압 관찰기 무료 대여) → **정상 기준** 관찰 2곳(왼심실 대동맥판 아래: 심장이 짤 때 피가 벽을 가장 세게 미는 힘 / 대동맥 굴·관 이음부: 심장이 쉴 때도 대동맥 벽이 되돌아오며 미는 힘, 숫자 두 개의 뜻) → 오름대동맥 앞 **혈압 관찰기**에서 한 가지씩 바꿔 비교(쉴 때 기준 → 막 움직인 뒤 → 쉬어도 계속 높음, 막 움직인 뒤부터 기록) → 내 자리 자료 3단계(왜 높아질까 / 무엇을 보면 알 수 있을까 / 몸을 돕는 원리) → 혈압 기록 도해 → 쉬운 설명·팩트체크 기사 → 독자 반응. 새 맵은 없고 기존 대동맥 뿌리 공간을 쓴다.

**혈압 기록 도해** (가상 인물 가온 씨의 기록 카드, 숫자 대신 ‘벽을 미는 힘’ 막대):

1. **평소 혈압을 볼 기록 고르기:** 첫째·둘째·셋째 날 아침 집에서 앉아 쉰 뒤 잰 기록 3장이 정답. ‘병원 · 계단을 뛰어 올라온 직후’(재는 조건이 다름)와 ‘언제·어디서 쟀는지 적히지 않은 기록’(비교 불가)은 감점 없이 힌트로 거절한다.
2. **기사에 쓸 판단 고르기:** ‘한 번 높게 나온 숫자만으로는 정할 수 없어요. 쉬고 바르게 잰 기록을 여러 날 모아 의료진과 함께 봐요’가 정답. ‘한 번 높게 나왔으니 고혈압’(관찰을 진단으로 바꿈)과 ‘신경 쓰지 않아도 돼요’(고혈압은 대개 느낌이 없음)는 힌트로 거절한다. 틀린 카드는 저장되지 않는다.

## 질환 레이어 (기본)

혈압 관찰기는 오름대동맥 양쪽 벽으로 향하는 화살표 길이와 ‘벽을 미는 힘’ 막대로 힘의 차이를 정성적으로 보인다(`src/domain/pressure-model.ts`, HeartView `pressure`·`pressureHigh`). ‘쉬어도 계속 높음’만 붉은 색으로 고혈압 기초 레이어를 표시한다. 렌더링 전용: 박동·판막 통과·충돌·보상은 바뀌지 않고 비교 창을 닫으면 쉴 때로 돌아온다. 화살표와 막대는 측정값이 아니다.

## 기본 난이도 계약 점검 (설계 19 3절)

- 일상어 먼저: ‘피가 혈관 벽을 미는 힘’을 먼저 보이고 ‘혈압’, ‘고혈압’ 이름을 붙인다. 새로 외울 이름 2개.
- 숫자 없음: 화면 문장(의뢰·관찰·비교·자료·도해)에 숫자가 없고 mmHg 표기도 없다. check_design과 check_game_build가 검사한다. 진단 기준 수치·유병률·나이 기준은 쓰지 않았다.
- 약: ‘의료진과 함께 약으로 치료하기도 해요’ 한 줄만, 약 이름·계열 없음. 위험 계산·합병증 없음(심화).
- 낙인 금지: 관리할 수 있는 요인 카드에 ‘일하는 환경과 사는 형편도 영향을 줘요. 한 사람의 잘못만으로 생기는 게 아니에요’를 넣었다.
- 행동 먼저·실패 없음: 관찰과 비교가 자료보다 먼저이고, 틀린 카드는 감점 없이 힌트.
