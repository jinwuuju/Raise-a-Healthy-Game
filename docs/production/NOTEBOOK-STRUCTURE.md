## 기록의 주 분류

| 분류 | 소유하는 정보 | 다른 분류와 연결 |

| 취재 파일 | Q001 독자 질문·단계·필수 관찰 A/B·출처·초안 이어 쓰기 | 발행 기사는 링크로 읽기 |

`application/notebook.ts`는 모든 `inspected` 키를 위 주 소유 범위에 한 번만 배정한다. Q001 근거와 `hx:` 탐험 구조, 장소 기록을 구별하고 알 수 없는 옛 키는 버리지 않는다. 개수/링크는 요약이며 동일 기록 본문을 여러 목록에 넣지 않는다.

## 화면·조작

- 5개 분류 탭, 하나의 활성 패널. 모바일 세로는 3+2줄, 넓은 화면은 한 줄이다. 탭은 48px 이상이며 키보드 좌/우/Home/End로 선택한다.
- 취재 파일은 의뢰→관찰→보고→발행의 단계, 근거별 토글. 인체 탐험은 기관→방→구조 토글이다. 발견한 구조만 상세를 만들고 미발견은 개수/탐험 안내로 요약한다. 38개의 `???` 목록을 한꺼번에 표시하지 않는다.
- 발행 반응은 최신 한 회차와 접힌 지난 회차 목록. 상세는 당시 결과창으로 연결하며 새 추첨/지급이 없다. 상세 반응이 최근 20회로 제한된 경우 누적 횟수와 상세 보관 범위를 표시한다.
- 선택한 탭/접힘은 같은 세션의 다시 열기에서 유지한다. 게임 도메인이나 저장 필드를 바꾸는 UI 설정은 아니다. 새로고침하면 기본 탭으로 시작한다.
- 본문을 읽거나 토글할 때 창이 닫히지 않는다. 닫기/바깥/Esc로 복귀한다. 출처 링크·검수 전 표시·편집국에서만 쓰기/재발행 조건을 유지한다. 현재 목표에서 글쓰기를 바로 열 수 있다.
- 시트의 Tab 잠금 대상에 native summary도 포함하여 접힌 기록을 키보드로 건너뛰는 문제를 방지했다. 가로·세로와 rem 글자 200%에서도 분류/본문/글쓰기 경로를 유지한다.
