# 심장 구조 정확성·연결 탐험 계약

2026-10-11 · 사용자 지시: 인체 구조는 디테일과 정확성이 핵심이며, 구역은 나중에 하나의 기관 안에서 이어 탐험하는 경험으로 발전해야 한다.

## 이번 구현의 경계

심장 입구·네 방·판막·순환·전도계·심근 공급·조건 취재의 일곱 구역을 연결한다. 구역 사이의 보행 통로는 기자의 탐험 동선이다. 혈액이 실제로 이동하는 통로와 혼동하지 않게 지도·도감에서 구분한다. 취재를 받은 구역에 걸어서 이동하거나 전체 지도에서 다시 들어갈 수 있다. 다음 취재의 수락·보상은 편집국에서 진행하며 무료 탐험·도감 열람을 구매로 막지 않는다.

별도의 심장 절개 개념도에는 네 방, 네 판막, 중격, 상·하대정맥, 폐동맥·폐정맥, 대동맥, 관상동맥, 동방결절·방실결절·히스속·좌우 각·푸르키네 섬유를 표시한다. 구조 목록에서 하나를 고르면 위치·설명·출처를 함께 확인한다. 도감은 처음부터 무료이며 취재로 확인한 개념에는 별도의 기록 표시를 붙인다.

이 개념도는 입체 구조를 읽기 쉽게 펼친 도해다. 정밀 해부 모델·실제 절개면·수술 시뮬레이션이 아니다. 폐정맥은 쌍을 묶어 표시하고 관상동맥의 세부 분지는 생략한다. 해부학적 오른쪽은 정면을 보는 화면의 왼쪽이다. 크기·전도 시간·혈류량을 실제 측정값으로 표시하지 않는다. 초안은 **검수 전 모형**이며 전문가 검수·의료 승인은 남아 있다.

## 정확성 회귀 조건

- 상·하대정맥 → 우심방 → 삼첨판 → 우심실 → 폐동맥판 → 폐동맥 → 폐.
- 폐 → 폐정맥 → 좌심방 → 승모판 → 좌심실 → 대동맥판 → 대동맥 → 몸.
- 대동맥 → 관상동맥 → 심장근육. 심장정맥은 우심방 쪽으로 돌아온다.
- 중격을 가로질러 우심방→좌심방이나 우심실→좌심실의 정상 혈액 경로를 만들지 않는다.
- 전기 신호와 혈관을 별도 데이터·선·재생 모드로 구분한다.
- 동맥/정맥을 산소 색만으로 정의하지 않는다. 폐동맥은 상대적으로 산소가 적은 혈액, 폐정맥은 산소가 풍부한 혈액이다. 파란색은 도해의 구분색이며 실제 혈액 색이 아니다.
- 연결 구역의 길은 혈관 관계를 대신하지 않는다. 구역 위치와 보행 거리는 게임용이다.
- 도감 그림의 구조 선택 위치, 화살표, 판막 표현을 실제 화면에서도 대조한다. 참조 ID·연결 그래프 검사는 의학적 그림 검수를 대체하지 않는다.

## 이후 확장

심장 세부 구조(심내막·심근·심외막, 판막 첨판·건삭·유두근, 관상동맥 분지, 전도계의 세부 위치)를 추가할 때는 항목별 출처·위치·연결·표현 한계를 먼저 기록한다. 사람의 오른쪽/왼쪽과 절개면을 유지하고, 더 자세한 도해를 추가해도 기존 개념도와 저장 진척을 보존한다.

다음 기관은 전신 아틀라스의 기관 ID를 부모로 삼고, `구조 → 연결 → 역할 → 관찰 근거`를 공유한다. 심장·폐 연결처럼 실제 기능적 관계를 따라 기관 간 길을 만들되, 모든 계통이 이번 P3에 구현되었다고 표시하지 않는다. P4 이후 일정과 실제 의료·아트 검수 게이트는 원래 작업 큐에 남는다.
