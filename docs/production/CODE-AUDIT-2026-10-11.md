# QA-01 오류 점검·수정·최적화

2026-10-11 · 사용자 요청: 현재 코드의 오류·버그·잠재 문제 수정 및 최적화. 추가 요청: 양팔의 반대 흔들기, 클릭 없는 바디스코프 입장 창.

## 범위

입력: `main`의 redesign-1/Q001 입구 런타임, 저장·application·도메인·월드·그래픽·UI, 기존 단위/브라우저 검사와 배포 검사. 시작 시 로컬 변경 없음과 README/STATUS/DECISIONS/BACKLOG/HUD 원칙을 확인했다.

출력: 아래 결함 수정과 회귀 검사, D051~D053, 현재 STATUS/작업 큐. 퍼즐·기사·추가 보상·아트/의학 승인은 구현 범위에 넣지 않았다. balance/content 원본 수치는 변경하지 않았다.

## 최적화와 측정

- 고정 지도 충돌을 타일별 공간 인덱스로 조회하고, 길찾기의 격자·간선 충돌 결과를 방별로 재사용한다. 막힘 없는 가까운 탭은 A* 배열을 만들지 않는다. 이 캐시는 현재 고정 기하에 적용되므로 앞으로 이동 장애물/가변 지형을 도입하면 무효화 설계를 먼저 추가해야 한다.
- 270개 외형 조합 × 4방향 × 4프레임(4,320개 프레임) 생성 후 캐시는 **256장**이며, 처음 프레임을 다시 만들었을 때 픽셀이 동일하다. 브라우저 전체 메모리나 실제 기기의 장시간 메모리를 측정한 결과는 아니다.
- 같은 로컬 Chromium에서 짧은 편집국 경로와 거리→카페 경로를 합계 800회 계산한 5회 표본: 원본 중앙값 **66.4ms**, 안전 검사·캐시를 포함한 최종 중앙값 **72.7ms**(최종 회당 약 0.091ms). 원본보다 전체 경로 시간이 빨라졌다고 주장하지 않는다. 보강 직후의 계산 증가를 캐시·공간 인덱스로 줄였으며 핵심 성과는 경로 안전성과 외형 메모리 상한이다. 표본은 로컬 `artifacts/audit-before.json`, `artifacts/audit-after.json`에 기록했다.

## 실제 검증

- `npm run typecheck`, `npm test`: **78개** 통과. 시작 시 기존 61개 통과, 새 저장/충돌 회귀 10개는 수정 전 모두 실패했고 수정 후 통과했다. 차량 정지선·보행자 회귀 2개도 수정 전 실패를 관찰했다.
- `npm run test:e2e`: **17개** 통과. 첫날 동선·Q001 왕복·보행 신호·기존 모바일 HUD/창/미리보기에 새 저장 오류·두 탭·포커스·자동 입장 창·캐시 검사를 포함한다. 마지막 포커스 복귀 조정 후 해당 편집 Esc 경로 1개도 별도 재검사 통과했다.
- `npm run build` 및 Q001 draft+면책 문구/본문 분리 빌드 경계 통과. JS gzip 약 **57KB**, 외부 이미지 자산을 추가하지 않았다.
- `python3 tools/check_design.py`, `python3 tools/build_site.py`, `python3 tools/check_site.py` 통과. 의학 검수나 실제 학습 효과 검증을 의미하지 않는다.
