## 게임 구현 상태

Phaser 게임·실제 의상 구매·집 배치·의학 콘텐츠 검수·플레이테스트는 아직 없다. 웹사이트의 외형/레벨/경제는 설계 미리보기다. 모든 아틀라스 항목은 planned이고 실제 의학 정보 승인본이 아니다.

기본 셸 PATH에는 Node가 없지만 앱 번들 Node 경로는 확인했다. 정적 설계실은 Python 표준 라이브러리로 생성한다. 게임 도구체인의 정확한 버전 고정은 P1에 남아 있다.
