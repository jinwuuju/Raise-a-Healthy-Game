## 실행과 미리보기

로컬 프로덕션 미리보기: `http://127.0.0.1:5190/`. 실행 중인 이 Mac에서만 이용 가능하며 원격 배포가 아니다. 시작 화면을 앱 브라우저에 열어 확인했다. 표준 도구 환경은 `npm ci` 후 `npm run dev`; 이 Mac의 셸에서 Node/npm이 없으면 `bash tools/npm-local.sh run dev`를 사용한다.

프로덕션 preview 서버는 `bash tools/npm-local.sh run preview -- --port 5190 --strictPort`. 브라우저 저장은 원점/포트별로 분리되므로 dev/preview를 바꿀 때는 파일 export/import로 이어갈 수 있다.

- 4방향 각각 8단계 보행 사이클, 이동 거리6px마다 프레임 진행, 정지 시 바라보는 방향 유지. 발점/깊이는 고정한다. 일부 단계는 같은 포즈를 공유하며 8개의 고유 아트 포즈라고 주장하지 않는다.
- 출입구12px 영역으로 실제 이동해 들어가면 application이 장면을 전환한다. 건물 클릭이나 출입 버튼은 필요 없다. 도착점을 문 밖으로 분리하여 왕복/저장 복원 때 즉시 재진입하지 않는다.
- 메뉴의 취재수첩·기자 정보 중복을 제거했다. 수첩과 왼쪽 기자 칩은 HUD에서 직접 열고 관리 메뉴는 기록·저장과 조작 안내에 집중한다. 외형 선택 화면은 선택 필드와 고정 미리보기로 구성했다.
- schema3/foundation-3. schema1/2의 이름·종류·진척을 유지하고 기본 외형/소유 기본 의상을 추가한다. 첫 변경 저장 시 이전 원본을 보관한다.
- 실제 검증: 단위·통합17개, Chromium E2E18개 통과. 외형 생성/수정/재실행·HUD/월드 일치·4방향 프레임 변화·문 자동 출입과 재진입 방지·저장/복구·모바일 가로/세로를 포함한다. 실제 기기 조작감과 아트 승인은 별도다.

- 최종 타입/프로덕션 빌드·배포 자산 경계 검사 통과. 설계841개, 설계실33문서/185링크·자산 검사 통과. 로컬5190 HTTP200 확인; 기존 탭은 새로고침 후 적용된다. 원격 배포는 수행하지 않았다.
