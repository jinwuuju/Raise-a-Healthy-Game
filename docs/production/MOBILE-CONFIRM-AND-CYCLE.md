# 모바일 확인 버튼과 접는 심장 주기

2026-10-11 · D064 · 사용자 지정: 모바일 오른쪽 아래 확인 버튼, 심장 주기 접기/펼치기, 배포.

## 구현 범위

- 확인 버튼: 왼쪽 조작볼과 중심 높이가 같은 오른쪽 엄지 위치. 기본 64px, 짧은 가로 화면 60px 원형 터치 영역, 반투명 유리색과 얇은 금색 테두리·청록 확인 표시. PC와 생성/메뉴/지도/기사 시트에는 숨긴다. 대상이 없을 때는 흐리고 비활성화한다.
- 월드에서는 가까운 사람·구조를 조사/대화하고, 대화 중에는 글자 출력 완료/다음 줄/닫기만 한다. 선택지가 나타나면 확인 버튼을 숨기고 해당 선택지를 직접 누르게 한다. 보상·구매·바디스코프 입장을 자동 선택하지 않는다.
- 터치 이벤트를 직접 처리하고 뒤따르는 합성 클릭을 억제해 한 번의 터치가 대화를 두 번 넘기지 않게 한다. 월드 이동은 중단하고 눌렀던 조작볼도 정리한다. 대화창은 조작 영역 위에 놓고, 확인 버튼을 대화의 접근성 소유 관계와 포커스 잠금에 포함한다.
- 심장 주기: 헤더를 눌러 상세를 접고 펼친다. 모바일은 처음 접힌 상태, PC는 펼친 상태다. 사용자 선택은 같은 세션의 방 이동에서 유지되며 새로고침하면 기본값으로 시작한다. 펼치면 단계·박동 그래프·판막 상태·길 안내가 보인다. 접으면 상세 터치 영역을 없애고 그래프 렌더링도 생략한다. 미니맵은 계속 보인다.
- 모바일 가로는 미니맵 옆에 주기/메뉴를 배치해 접거나 펼쳤을 때 확인 버튼과 겹치지 않게 한다. 안전 영역을 고려한다. 게임 진행·의학 내용·보상 수치 변경은 없다.

`src/ui/confirm.ts`는 입력만 전달하고 도메인 진행은 기존 application 명령을 거친다. D042의 상시 행동 버튼 제거를 터치 화면에 한해 사용자 요청으로 대체한다. 이전 D062 의학 교정과 D063 첫 기사도 이번 사용자 요청 배포 대상에 포함하며 기존 로컬 작업을 보존한다.

## 확인한 것

관련 Playwright 10개 통과(새 검사 6 + 기존 터치/지도 4):

- 390×844, 844×390에서 중심 높이 일치, 터치 영역 48px 이상, 대화창/주기/확인 버튼 겹침 없음.
- 실제 터치 에뮬레이션으로 대상 대화, 한 번의 터치당 한 번 진행, 합성 클릭 중복 방지, 모달 포커스·이동 누출 방지.
- 포인터 이벤트 없이 TouchEvent만 보내는 경로에서 바디스코프 선택지가 정상 표시되고 자동 입장은 하지 않음.
- 모바일 주기 초기 접힘·펼침·길 안내·닫은 뒤 상태 유지, PC 확인 숨김·키보드 토글.
- 캡처 6장 `artifacts/mobile-controls/` 시각 확인. 실제 기기·사파리·시각적 만족도·전문가 검수는 별도다.

전체 회귀 검사와 배포 결과는 STATUS의 D064 기록과 이 작업의 실제 Actions/공개 URL 확인으로 구분한다.

최종 로컬 타입·프로덕션 빌드·draft 경계, 단위 **171개**·브라우저 **39개** 전체 통과(약 2.3분, 재시도 없음). JS gzip 91.15KB. 설계 877개, 설계실 42문서/246링크·자산 검사 통과. 사용자 요청에 따라 D062~D064를 main에 반영하며, 이 로컬 검증을 원격 배포 성공으로 간주하지 않는다.
