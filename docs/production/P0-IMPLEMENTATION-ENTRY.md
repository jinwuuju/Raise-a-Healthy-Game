# 구현 착수 전 내부 검토

2026-10-10 · 사용자 요청: 설계에서 실제 구현으로 전환하고 큐 순서에 따라 진행.

이 기록은 에이전트의 설계 문서 기반 탁상 검토다. 실제 독자의 역할극·시간 측정·아트 승인·의학 검수를 수행한 기록이 아니다. D025에 따라 의료 본문이 없는 P1 기반 실험을 시작한다. P0 전체 승인과 P2 진입은 별개다.

## P0-01: Q001 카드 순서 내부 검토 2회

입력: 첫 10분 명세, Q001 계약 예시, 생활 설계. 출력: 아래 카드 순서와 재개 규칙. 제외: 실제 의학 본문 작성·사용자 반응·완료 시간 실측.

| 순서 | 정상 경로 검토 | 힌트·중단 경로 검토 | 구현에 넘길 규칙 |
|---|---|---|---|
| 1 | 프리셋 선택 또는 기본 시작 | 이름·세부 외형을 건너뜀 | 능력 차이 없음, 무료 기본값 |
| 2 | 편집장 → 의뢰 수락 | 대사 닫기 → 다시 조사 | 수락 전 탐험 보상 없음 |
| 3 | 장치 → 입구 → 관찰 A/B | 관찰 A 뒤 중단·복원 | 안전 위치와 관찰 ID 저장 |
| 4 | 연결 타일 → 적용 | 무료 힌트, Esc, 재개 | 배치/힌트 수준 보존, 재시도 비용 없음 |
| 5 | 출발점이 다른 변형 | 시연 후에는 다른 변형 재수행 | 시연과 독립 수행 증거 구분 |
| 6 | 귀환 → 기사 3슬롯 | 근거 부족 초안 저장 → 재탐험 | 발행 조건은 명시적 근거 연결 |
| 7 | 첫 발행 → 무료 외형·숙소 안내 | 중복 클릭·재실행 | 20+30+50XP=100XP, 100G는 최초 1회 |
| 8 | 다음 취재 또는 귀가 | 상점·집 구매를 건너뜀 | 생활 기능은 취재의 입장 조건 아님 |

기사 모형: ‘관찰한 표식’ → ‘이어진 경로의 근거’ → ‘모형에서 확인한 범위와 한계’. 정확한 의료 문장과 rubric 허용 조합은 P2 이전 별도 콘텐츠 작성·검수 대상이다. 이동·패널·저장 문제부터 검증하기 위해 이번 빌드에는 Q001을 넣지 않는다.

발견한 수정점: 첫 구현에서 준비 중인 장치를 열린 취재로 표현하지 않는다. 이동 후 현재 위치 저장을 명시하며, 조사/전환 저장과 구분한다. 첫 외형 보상·숙소는 Q001의 진행을 막지 않도록 별도 선택 동선으로 남긴다.

## P0-02: 경제 장부 검토

원본 수치 변경 없음. Q001~Q010 총 2,700XP·2,270G, Lv.10. 무료 힌트와 필수 도구 대여에 비용 없음.

| 경로 | 지출 | 최종 잔액 | 문서상의 필수 진행 |
|---|---:|---:|---|
| 무구매 | 0G | 2,270G | 가능 |
| 업무 우선 | 250+600G | 1,420G | 가능 |
| 집 우선 | 250+200+1,500G | 320G | 가능 |
| 꾸미기 우선 | 350+400+250G | 1,270G | 가능 |

노트는 Q003까지 누적 370G에서 구매 가능. Q006까지 누적 960G에서 노트 구매 뒤 710G로 책상 600G 가능. 장식 먼저 구매해 선택 장비 구입이 늦어져도 기본 근거 목록/초안 슬롯으로 필수 진행 가능하다. 이 판단은 설계 검사이며 실제 Lv.10 완주 테스트가 아니다.

## P0-03: 첫 의료 콘텐츠의 범위

| 주장 후보 ID | 후속 검토 범위 | 출처 후보·절 | 상태/한계 |
|---|---|---|---|
| q001.circulation | 되돌아오는 흐름과 경로의 연결 | [OpenStax 19.1](https://openstax.org/books/anatomy-and-physiology-2e/pages/19-1-heart-anatomy), Chambers and Circulation through the Heart / Figure 19.4 | 본문 확인; 한국어 문장·도해·과제 검수 전 |
| q001.pump | 심장과 혈액 이동의 관계 | 같은 절, pumping chambers 설명 | 본문 확인; 펌프 비유의 한계 검수 필요 |
| q001.model-limit | 배달표/경로 타일은 교육용 모형 | 자체 모형 설명, 실제 구조 대조는 위 도해 후보 | 크기·위치·시간·산소화·두 순환의 생략 범위 명시 필요 |

현재 `review: null`. 전문 검수자 확보 여부 미확인. 임상 수치·진단·치료·질환 콘텐츠는 첫 루프 범위에서 제외한다. 원문 도해는 게임 자산으로 복사하지 않았으며, 출처 본문 확인은 콘텐츠 승인과 다르다.

## P0-ATLAS와 P0-ART

148개 초안의 ID/표제 중복 0개, 허브 참조 12개를 구조적으로 확인했다. 실제 해부 구조 누락·의학 분류 적절성·148개별 주장 출처 매핑은 미검수다. 분야별 패키지에서 source/review를 채우며 원본 planned 상태를 유지한다.

P0-ART 명세를 구현 입력으로 확인: 640×360 논리 화면, 32px 그리드 후보, 발 앵커/작은 footprint, 발 y 정렬, 가림 시 투명화. 이번 P1은 자체 도형만 사용하는 G0이며 4방향 스프라이트·기준 장면 G1·조합 G2는 제작/승인 전이다. 단가 측정은 아직 0건이며, 다음 아트 표본 1장면·프리셋 3종의 제작시간/손수정/가림 오류를 기록한 뒤 양산을 판단한다.

## P0-04: 이번에 고정한 범위

이번 작업의 대표 ID는 **P1-01**, 연결 검증을 위한 P1-02/03/04/05의 최소 G0 구현을 포함한다. 정상 설치·타입 검사·빌드·브라우저 실행까지 확인한다.

포함: 로컬 도구체인, 편집국과 임시 로비, 세 기본 프리셋/이름, 이동/충돌/조사, native HTML dialog, IndexedDB revision/원자 저장, 두 탭 쓰기 정책, 파일 내보내기/불러오기와 최근 정상 저장 2개.
