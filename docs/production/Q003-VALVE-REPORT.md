# Q003 판막 취재와 질환 비교

2026-10-12 · D074 · 사용자: “이어서 진행하고 배포해 오류 없는지 체크”.

## 구현 범위

Q002 발행 후 편집장 의뢰 → 정상 삼첨판·폐동맥판을 실제 위치에서 관찰 → 우심방 삼첨판 앞의 정상/협착/역류 비교 → 편집국 내 자리의 원인·맥락 자료 → 가상 검사 자료 해석 → 관리·수리·교체 원리 자료 취재 → 모형의 한계를 밝히는 팩트체크 기사 → 별도 독자 반응. 강제 진단 퀴즈나 개인 위험 계산은 없다.

정상 두 곳을 먼저 관찰해야 질환 비교가 열린다. Q002 기록에서 소급 완료하지 않는다. 비교는 기존 우심방의 동일 삼첨판 좌표와 HeartView를 사용한다. 새 맵을 복제하지 않는다. 비교 창은 같은 좌표의 충만기(위)와 심실 수축기(아래)를 정상/선택 상태로 함께 보여 준다. 월드에도 선택한 레이어가 투영되며, 저장 후 재시작하면 그 상태를 표시한다. 닫기/방 이동은 application 명령으로 정상 상태로 복귀한다. 모바일에서도 정상/선택 그림을 나란히 두고 가로 화면은 설명과 그림을 나눠 배치한다. 동작 줄이기에서는 고정된 단계 그림이고 바뀌지 않은 그림을 매 프레임 다시 그리지 않는다.

협착의 열림 정도와 역류의 되돌아가는 표식은 정성적 그림이다. 혈류량·중증도·개인 검사 측정값이 아니다. 기자 이동/충돌/역방향 차단은 기존 정상 판막 주기를 유지한다. 질환 레이어가 기자를 가두거나 역방향 출입을 만들지 않는다. 모든 상태·메모·기사·보상은 Game(application) 명령으로 저장한다. 렌더링은 상태를 읽는다.

원인 자료→검사 자료→관리 원리는 근거와 취재 메모를 차례로 모은다. 검사 A/B 및 녹취는 가상 자료임을 표시한다. 약 제품/용량/복용법·개인 치료 추천·응급 행동 안내는 없다. 기사 표현 선택지는 자료 범위의 동등한 표현이며 기사 점수를 의학 실력으로 주장하지 않는다. 합병증 기관은 준비 중으로 둔다.

## 저장·보상·수첩

schema4 유지, 없는 `q003`는 빈 의뢰로 이행한다. 선수 Q002 발행, 정상 먼저, 비교 먼저, 자료 취재 순서, 기사 근거/한계, 발행 키와 영수증의 일치 검사를 추가했다. 기존 Q001/Q002 기사와 반응을 보존한다. 보상은 기존 Q003의 200XP·150G 1회, 합계 450XP/Lv.4. 관찰·비교·자료 단계에는 별도 보상을 추가하지 않는다. 수첩 단일 소유: 정상 관찰·기관 자료 본문은 취재 파일, 협착/역류 비교 본문은 인체 탐험의 심장 아래 질환 비교, 완성 기사는 발행 기사. 다른 곳은 링크다. 공개 질환 도감은 만들지 않았다. 질환 파일의 `publicAtlas`는 false, 본문은 Q003 취재 안에서만 ‘검수 전 모형’으로 사용한다.
