## P1-HUD / D033

사용자 요청으로 월드 중심 HUD·상황별 조사·접는 목표·2단계 저장 메뉴를 구현한다. 데스크톱 메뉴·키보드·복구와 모바일 가로·세로 터치 에뮬레이션 검증 통과; 실제 기기 검증은 남음. STATUS에 결과 기록. 상점·기사·도감 등 후속 화면은 HUD 개발 원칙을 먼저 읽는다. 저장/보상 변경은 범위 밖이다.

## P1-AVATAR / D034~D036

사용자 지정 외형 편집·4방향 거리 기반 보행·문 자동 출입·메뉴 중복 제거 구현. 단위/통합17개와 브라우저18개 통과. 옷가게 구매·추가 의상 제작·실기기 조작감·전체 아트 승인은 후속이며 P3-SHOP 완료로 처리하지 않는다. 이후 모든 장착은 application의 소유 검증을 거쳐 월드/HUD/미리보기에 동시에 반영한다.
