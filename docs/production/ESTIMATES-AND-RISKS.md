# 제작 추정과 위험 관리

## v0.1 기준 추정 (현재 범위의 일정이 아님)

1~2인 개발 중심, 최종 아트·의학 검수는 별도 역량 확보를 가정한다. 아래는 **개발/통합 인주**의 거친 범위로, 아트·의료 검수·외부 대기·개인 가용 시간은 포함하지 않는다. 작업량을 달력 주수로 그대로 읽지 않는다. 최초 실측 전 신뢰도는 낮다.

| 단계 | 개발 인주 가설 | 범위를 좌우하는 요인 |
|---|---:|---|
| P0 | 1~2 | 설계 검토·검수 인력 확보 |
| P1 | 2~4 | 엔진·저장·UI 연동 경험 |
| P2 | 3~5 | 첫 퍼즐의 재미·기사 연결 |
| P3 | 5~9 | 7구역·10임무·도해·수정 |
| P4 | 3~6 | 경제·제작 파이프라인 |
| P5 | 6~10 | 새 기관 조작·기존 구조 재사용 |
| P6 | 12~20 | 6계통 추가·검수·성능 |
| P7 | 10~18 | 고급 취재·전문성 경로 |
| P8 | 4~8 | 전구간 QA·배포·저장 복구 |
| 합계 | 46~82 | 실측 전 범위; 아트/검수 별도 |

합계는 일정 약속이 아니다. P4에서 실제 제작시간에 따라 수량·일정·인력을 재조정한다. 확장 콘텐츠의 유지 비용이 크면 단순히 레벨 간 XP를 늘려 때우지 말고 선택 콘텐츠 수·구역 크기를 줄이는 범위 변경을 검토한다.

## 제작 단가 기록

취재마다 기획 시간, 의학 출처 확인, 회색상자, 데이터 작성, 아트, 검수, 테스트, 재작업을 따로 기록한다. 지역마다 새 조작과 재사용 조작 비중도 기록한다. `남은 종류별 개수 × 실측 중앙 제작시간 × 재작업 계수`로 추정하고 검수 병목은 독립 일정으로 본다.

## 위험 목록

| 위험 | 조기 신호 | 대응 | 담당 역할/확인 시점 |
|---|---|---|---|
| 초반이 재미없음 | 조작보다 대사 읽는 시간이 김 | 동선 축소·관찰 피드백 강화 | 기획 / P2 |
| 의학 모형이 오해를 만듦 | 조작 비유를 사실로 설명함 | 도해·단순화 안내·모형 수정 | 의료 검수 / 각 콘텐츠 |
| 99레벨이 노가다 | 새 임무 없이 같은 행동 반복 | 체크포인트 보상·콘텐츠 예산 조정 | 시스템 / P5+ |
| 규모 폭증 | 기관마다 공통 코드 복제 | 조작 계약·공통 편집/저장 재사용 | 개발 / P4 |
| 저장 손실 | 발행 직후 새로고침에서 차이 | 트랜잭션·원장·백업·이행 fixture | 개발 / P1 |
| 검수 병목 | 초안만 쌓이고 승인 안 됨 | 제작 배치 축소·검수 용량만큼 발행 | 제작 / P0+ |
| UI 접근 불가 | 캔버스·드래그만으로 진행 | DOM 설명·키보드 대체 | UX / P1+ |
| 라이선스 누락 | 출처 없는 임시 이미지가 배포됨 | asset manifest·배포 allowlist | 아트 / P2+ |
| 기술 버전 혼용 | Phaser 3 예제가 4에서 실패 | 정확한 버전과 smoke 검증 | 개발 / P1 |
| 지역 반복감 | 이름만 다르고 하는 일이 같음 | 계통별 조작-개념 검토 | 기획 / P5 |

역할은 필요 책임이며 실제 담당자가 배정되었다는 뜻이 아니다. 독립 의료 검수 역량이 없으면 공개 출시 전에 확보해야 한다.

## v0.2 추가 작업량과 예산 재산정

위 46~82 개발 인주는 v0.1 기준을 남긴 기록이다. v0.2에는 캐릭터/의상/상점/주거12~22인주, 전신/기자가이드 확대14~24인주, 통합/성능/회귀6~8인주를 더해 **78~136 개발 인주**를 임시 가정한다. 아트 제작·의료 검수·외부 대기는 여전히 별도다. 이 합계는 계획 가설이지 달력 출시일이 아니다.

새 위험: 의상 레이어 호환 조합 폭증, 집 가구 출입구 차단, 모든 의학 완성이라는 범위 착시, 아트 지연, 외형에 의학적 능력 보너스를 붙이는 불균형. 대응은 소수 기준 자산의 품질 게이트, 커버리지 장부, 무료 필수 진행, 단계별 수량 상한이다.
