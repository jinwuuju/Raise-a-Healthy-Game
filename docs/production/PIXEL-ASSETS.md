# 픽셀 아트 자산과 생성 프롬프트 기록

2026-10-10. **내장 imagegen 도구**로 생성한 원본 PNG를 프로젝트에 복사하고 Phaser의 sprite/frame으로 사용했다. 사진/기존 게임의 UI나 타일을 게임 파일에 복사하지 않았다. 지역 외관 참고와 최종 아트 승인/G1/G2는 별개이며, 현재 자산은 사용자 피드백을 받는 첫 통합 표본이다. 생성된 시트의 그리드가 완전히 균일하지 않아 실제 출력에 맞춰 프레임 범위와 발점을 등록했다. 향후 프레임 손질·6프레임 보행·의상 합성은 남아 있다.

지붕·전면·보도는 한 배경 이미지로 합치지 않았다. PNG 오브젝트/배경 타일/캐릭터/표식/HUD를 각각 렌더링한다. 발 y 정렬·가림·application 충돌과 연결했으며, 지형·차량·임시 카페 카운터는 코드로 만든 픽셀 표현이다. 사용하지 않은 초기 전원풍 생성물은 런타임에 넣지 않았다.

## 최종 프롬프트 세트

아래는 사용한 자산별 생성 명세를 보관한 것이다. 각 문단은 개별 내장 도구 호출이고 이미지 편집 CLI는 사용하지 않았다.

### Reporters

Use case: stylized-concept. Asset type: ORIGINAL ACTUAL playable pixel RPG CHARACTER SPRITE SHEET, with true transparent background. Canvas 1536x768. EXACT GRID 12 columns and 3 rows: cells 128x256 pixels. Three original young adult newspaper reporters, one per row: row 1 male reporter dark curly hair sage green jacket cream shirt navy trousers brown shoes and messenger bag; row 2 female reporter chestnut bob hair cream shirt dark teal jacket charcoal trousers brown shoes and messenger bag; row 3 friendly fictional alien reporter light mint face small two antennae ochre jacket navy trousers brown shoes and messenger bag. Same baseline and same body proportions in all cells. Each character is compact crisp 32x48 logical pixel-art drawn at 4x scale, centered in its 128x256 cell with feet at local y=224, no sprite crosses a cell. COLUMN GROUPS: columns 1,2,3 walking facing DOWN; columns 4,5,6 walking facing LEFT; columns 7,8,9 walking facing RIGHT; columns 10,11,12 walking facing UP (back view). Within each group: frame1 neutral stand, frame2 left foot forward, frame3 right foot forward. Keep head, height, foot baseline and clothes absolutely consistent across all frames. Authentic careful 16-bit high-detail pixel clusters, layered jacket lapels and tiny light/shadow colors, dark readable outline, warm highlights. Slight elevated oblique overhead camera matching a top-down 2.5D pixel town. No exaggerated super-deformed oversized heads; approximately head 1/3 body height. Do not resemble an existing game's character. Transparent around sprites, no background, no ground shadows, no text, no grid lines, no painted checkerboard, no captions, no HUD, no smooth vector illustration. Pixel crisp edges; each sprite must read at the original small resolution. This sheet is used directly for actual animation in Phaser.
