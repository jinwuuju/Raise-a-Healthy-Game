# Q005 박자를 전하는 길 · 부정맥(심방세동) 동반

2026-10-13 · D077 · 사용자: “로컬과 GitHub를 맞추고 이어서 진행, 오류 없도록 꼼꼼하게”. 지침의 다음 순서(Q005 박동 신호 취재 + 부정맥 동반 범위 검토)를 구현한다.

## 플레이와 범위

Q004 발행 → 편집장 의뢰(신호 관찰기 무료 대여) → 신호가 지나는 다섯 곳 직접 관찰 → 우심방 동방결절 앞 신호 관찰기에서 고른 박자/심방세동 비교 → 내 자리 자료 취재 3단계 → 신호 도착 순서 도해 + 팩트체크 기사 → 독자 반응. 기존 여섯 내부 공간·판막 일방향·심장 주기를 유지하며 새 맵은 없다.

정상 관찰 다섯 곳은 기존 탐험 구조를 그대로 쓴다: 우심방 동방결절(`hx-sa`)·방실결절(`hx-avnode`), 우심실 조절띠(`hx-moderator`), 좌심방 바흐만다발(`hx-bachmann`), 좌심실 왼다발갈래(`hx-lbb`). 이전 탐험 기록·Q001~Q004에서 소급 완료하지 않는다. **걷는 순서(우심방→우심실→폐→좌심방→좌심실)와 신호 순서(동방결절→심방→방실결절→다발갈래)가 다르다**는 점이 기사 도해의 과제다. 설계 03의 ‘신호 표식 도착 순서 조정’과 ‘신호와 움직임 구분’을 카드 배치로 구현했다. 카드마다 이어지는 움직임(심방 수축·심실 충만 시간·심실 수축)을 함께 적어 신호가 먼저, 움직임이 그다음임을 보여 준다. 순서가 어긋난 카드는 감점 없이 거절되고 다음 단계의 힌트를 보여 준다(03의 실패 피드백). 두 다발갈래는 같은 마지막 단계라 어느 쪽을 먼저 놓아도 된다. ‘순서 다시 놓기’는 취재 기록을 지우지 않는다.

## 질환 동반(D071)

부정맥 첫 모듈은 흔한 유형인 **심방세동**이다. 정상 다섯 곳 뒤에만 같은 우심방에서 비교 레이어가 열린다(정상 → 질환). 레이어는 렌더링 전용이다: 심방 전체에 흩어진 끊긴 잔물결, 불규칙한 방실결절 도달, 고른 심방 수축 대신 떨림 표시. 판막 통과·충돌·심장 주기 창은 정상 주기를 그대로 따르며 진행·보상을 바꾸지 않는다. 6단계: 정상 기준 → 레이어 비교 → 원인·위험 요인 맥락(조직·신호 변화, 나이·가족력·동반 질환·생활 요인, 원인 없이도 생김, 개인 탓 금지) → 검사 자료(가상 심전도 모형 A/B, 한 번의 기록으로 개인 진단 불가) → 치료·관리 원리(혈전 예방·심박수 조절·리듬 조절, 약 이름·용량 없음) → 팩트체크 기사(불규칙한 맥박=심방세동이라는 오해). 개인 진단·위험 계산·치료 추천·응급 행동 안내는 없다.

장부: `data/catalog/diseases.v0.1.json`의 `disease.arrhythmia`(전도계 `anatomy.circulation.07`, Q005), 본문 초안 `data/content/diseases/arrhythmia.v0.1.json`(draft_unreviewed, publicAtlas false, 런타임 제외). 미검수 의학 본문은 Q005 취재 안에서만 ‘검수 전 모형’과 함께 표시한다. 다른 부정맥 유형(심실성·전도 차단 등), D076 박동 신호 제보·미스터리(EVT/MYS)는 이번 범위가 아니다. 합병증 기관(뇌졸중·심부전)은 ‘준비 중’ 연결이다.
