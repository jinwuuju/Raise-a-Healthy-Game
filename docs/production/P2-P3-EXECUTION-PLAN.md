## 구조·보존 계약

- JSON에 독자 질문·관찰·퍼즐 정의/변형·기전/한계·출처/확인일·검수 null을 둔다. 공식 NHLBI 본문을 주장별로 확인하고 원문 이미지·영상은 복사하지 않는다.
- 순수 도메인: 퍼즐 상태/판정·증거·선수 조건·기사 의미 연결·멱등 보상·구매. application만 진행 상태를 갱신하고 UI는 명령과 projection을 사용한다.
- 지도: 기존 편집국/거리/카페를 유지하고 심장 탐사의 일곱 개념 구역은 기존 픽셀 규격으로 추가한다. 실제 해부 배치/생리 시간·압력의 재현이라고 주장하지 않는다.
- 저장: 기존 schema4의 외형·위치·카페·Q001 관찰/20XP 보존. 새 캠페인 상태는 구버전 저장에서 안전하게 초기화하며 부분 초안·퍼즐·힌트·신문·구매를 복원한다.
- 기존 밸런스 Q001~Q010, 20+30+50XP, 필수 무구매 경로 유지. 선택 가격은 balance 원본에서 정하고 문서/설계 검사를 함께 실행한다.

## 검증과 종료

타입·실제 콘텐츠 Schema/참조/해금/해답 검사·도메인 회귀·실제 브라우저 P2/P3 전체 흐름·모바일 퍼즐/기사·저장 실패/불러오기·빌드 draft 경계를 확인한다. 각 완료 시 STATUS/결정/큐를 갱신한다. 검증 후 main 배포와 공개 번들/동작을 확인한다. 인간 재미·정확성 검토를 자동 검사 통과로 표시하지 않는다.
