생활 맵(집·거리·가게·편집국)은 위 인체 탐험 맵에 포함하지 않는다. 1.0 생활 장소는 편집국4단계, 주거5단계, 생활 골목, 옷가게, 가구점, 카페, 자료관을 우선한다. 공간 공유 여부는 실제 아트 단가를 측정해 조정한다.

## 구간당 제작 배분

메인 취재: 1~10 10개, 11~20 12개, 21~30 12개, 31~40 12개, 41~50 12개, 51~60 14개, 61~70 12개, 71~80 12개, 81~90 12개, 91~99 12개 = 120개. 계통별 원소유 ID로 중복 집계를 막는다. 각 기획은 1~3개 개념과 연결하되 카드 수를 늘리려 내용 없는 항목을 만들지 않는다.

XP 공식은 v0.1을 유지한다. 초반 2,700XP로 Lv.10, 최종 401,850XP로 Lv.99. 후반 구간은 메인 취재 체크포인트 공급량이 필요량의 110~125% 범위인지 시뮬레이션한다. 생활 의뢰나 선택 취재가 필수 경험치 부족을 메우는 의무가 되면 반려한다. 콘텐츠 증가에 따른 시간 목표는 재검증 전이며 기존 40~60시간을 확정값으로 쓰지 않는다.

## 제작 단가와 축소 순서

검수된 고유 퍼즐 1개, 3몸 템플릿에 맞는 의상 1개, 가구 1개, 집 1개를 실측한다. 과부하 시 맵 크기·동시 출시 의상 종류·선택 의뢰를 줄이되 무료 정보 접근·저장 안정성·핵심 루프·의료 검수는 줄이지 않는다. 모든 신체 구조의 독립 맵 제작을 출시 요건으로 삼지 않고 관찰 지점/도해로 전신 기초 커버리지를 확보한다.
