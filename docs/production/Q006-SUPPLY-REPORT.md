# Q006 펌프도 배달이 필요해 · 심장 근육 공급 (정상)

2026-10-15 · D099 · 사용자: “이어서 진행해라”. 동네 1km(D098)까지 사용자 지시 범위가 끝났고, 남은 동네 항목(화면 확인·건물 이름·실기기)은 사용자 몫이라 지침의 다음 메인 순서인 Q006을 구현한다.

## 플레이와 범위

Q005 발행 → 편집장 의뢰(공급 관찰기 무료 대여) → 공급 노선 다섯 곳 직접 관찰 → 대동맥굴 앞 공급 관찰기에서 쉴 때/더 일할 때 비교 → 내 자리 자료 취재 3단계 → 심장 근육 배송 노선 도해 + 팩트체크 기사 → 독자 반응. 새 맵은 없고 기존 여섯 내부 공간·판막 일방향·심장 주기를 그대로 쓴다.

관찰 다섯 곳은 기존 탐험 구조를 쓴다: 우심방 관상정맥동 입구(`hx-cs`), 우심실 벽(`hx-rvwall`), 좌심실 벽(`hx-lvwall`), 대동맥굴의 오른·왼관상동맥 입구(`hx-rca`·`hx-lca`). Q004/Q005의 취재 지점과 겹치지 않고, 이전 탐험 기록에서 소급 완료하지 않는다. **걷는 순서(우심방 → 우심실 → 좌심실 → 대동맥)와 공급 순서(대동맥굴에서 갈라짐 → 심장 벽 근육 → 관상정맥동으로 돌아옴)가 반대**라는 점이 도해 과제다.

설계 03의 실패 피드백 ‘주 경로만 완성해도 보조 공급 누락 표시’를 이렇게 구현했다. 도해 위에 Q004의 주 노선(좌심실 → 대동맥판막 → 오름대동맥 → 온몸)을 주어진 선으로 보여 주고, ‘심장 근육 배송 · 아직 빠져 있어요’ 표시가 다섯 카드를 다 이을 때까지 남는다. 카드 더미에는 ‘오름대동맥 → 온몸으로 가는 큰길’ 미끼 카드가 함께 있고, 놓으려 하면 감점 없이 ‘주 노선만 이으면 펌프 근육의 배송이 빠져요’ 힌트로 거절한다. 순서가 어긋난 카드도 다음 단계 힌트로 거절한다. 두 관상동맥 입구, 두 벽은 같은 단계라 어느 쪽을 먼저 놓아도 된다. ‘노선 다시 놓기’는 취재 기록을 지우지 않는다. 설계 03의 해금 ‘6구역·근거 보드 확장’은 이번 범위가 아니다(구역·상점 장비 미구현은 Q005와 같음).

## 비교 레이어 (정상 조건, 질환 아님)

공급 관찰기는 같은 대동맥굴 화면을 두 칸에 나란히 그린다. ‘더 일할 때’는 관상동맥 흐름 표식을 넓히고 수를 늘리며 두 입구에 점선 고리를 그린다. 렌더링 전용이다: 박동 속도·판막 통과·충돌·보상은 바뀌지 않으며, 대동맥 밖으로 나가거나 바디스코프에 다시 들어가면 쉴 때로 돌아온다. 저장 검증도 ‘더 일할 때’는 대동맥에서만 허용한다.
