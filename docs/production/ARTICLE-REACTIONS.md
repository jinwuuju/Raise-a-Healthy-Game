# 발행 결과 · 독자 반응과 추가 골드

2026-10-11 · D065~D066 · 로컬 구현. D065 최초 제안의 품질 점수/추가 보너스 후순위를 D066 사용자 지시로 대체한다.

## 사용자 확정과 실제 흐름

경험치는 기존대로 유지한다. 반응 점수·댓글·연출은 기사 품질/표현/추가 탐험 기록과 독립적인 무작위 조합이다. 게임 화면에서 무작위를 매번 설명하지 않되 점수를 의학적 정확성·플레이어 실력·실제 독자 측정으로 주장하지 않는다. 기존 편집 확인과 의료 본문의 검수 전 상태는 유지한다.

발행→독자 반응 별도 창→신문 연출→점수 카운트→독자 3명 한마디→응원금·성장 결과로 이어진다. 기본 연출 3.2초, 결과 바로 보기/Esc/닫기 첫 입력은 최종 결과 표시, 최종 상태의 계속/Esc/닫기는 월드 복귀다. 동작 줄이기·중간 재실행·과거 결과 보기는 곧바로 최종 상태를 보여준다. 본문/바깥 탭은 발표창을 닫지 않는다.

발행 기사 읽기 화면의 ‘다시 발행 · 새 독자 반응’은 편집국에서 새 회차를 만들고 추가 골드만 준다. 이것은 사용자가 허용한 반복 골드다. 과거 결과 보기·스킵·저장 재시도·같은 발행 버튼의 늦은 중복 이벤트는 새 회차를 만들지 않는다. 최초 기사 본문과 canonical XP 완료 키는 그대로다.

## 수치 원본

`data/balance/article-reactions.v0.1.json`이 실행 원본이다.

| 항목 | 현재 값 |
|---|---:|
| 반응 점수 | 30~100 |
| 일반 응원금 | 20~160G |
| 뜻밖의 응원금 | 200~600G |
| 뜻밖의 응원금 확률 | 6% |
| 추가 XP | 0 |
| 재발행 기본 골드 | 0 (응원금은 다시 지급) |
| 저장하는 상세 반응 | 최근 20회, 누적 횟수/재화 보존 |
| 연출 | 3,200ms, 즉시 결과 지원 |

점수와 응원금은 각각 별도 추첨이다. 확률·배점은 보건/교육 지표가 아니며 순수한 게임 연출이다. 최초 발행은 관찰에서 이미 받은 20XP + 발행 80XP로 총 100XP/Lv.2를 유지하고, 골드는 기본 100G에 응원금을 더한다. 초반 경제 원본의 2,270G는 보장 기본 보상 합계로 유지하며 실제 잔액에는 반응 골드가 추가된다. 기존 P4의 최대 20% ‘품질 보너스’는 별개이며, D066의 무작위 응원금에는 적용하지 않는다. 필수 진척·상품 가격은 바꾸지 않았다.

`data/content/article-reactions.v0.1.json`: 가상 독자 16명, 댓글 48개, 제목 32개, 연출 6종. 한 회차에서 독자 3명과 댓글 3개는 서로 다르게 뽑으며 이름/댓글/제목/점수/금액/연출을 조합한다. 연속 발행 사이에 우연히 같은 요소가 나올 수 있으며 ‘항상 새 결과’라고 보장하지 않는다. 의학 본문은 생성/변경하지 않는다.

## 충돌 해결과 저장

- 기존 발행의 80XP·100G와 새 반응/응원금을 application의 한 상태 변경으로 확정한다. UI 연출 콜백은 보상·점수 상태를 바꾸지 않는다.
- `Game.publishArticle()`은 최초 발행에만 새 결과를 만든다. 명시적 재발행은 현재 회차를 인자로 받아 늦은 중복 이벤트를 구별한다. XP는 0이고 추가 골드만 지급한다.
- 저장 schema4에 선택 필드 `reactions`를 추가한다. 기존 저장은 빈 반응 기록으로 읽고 발행/골드/XP를 보존한다. 과거에 없던 점수나 보상을 소급 생성하지 않는다. 기존 발행 기사도 새 회차로 다시 발행할 수 있다.
- 결과 영수증은 회차/버전/점수/댓글·연출 ID/실제 XP·기본 골드·추가 골드/전후 재화/발행 시각을 저장한다. import에서 범위·회차·합계·중복 독자·발행 장부 관계를 검증한다. 규칙 버전 1의 콘텐츠는 과거 결과를 재현하는 계약이다.
- 쓰기 실패 시 디스크의 이전 기록을 보존하고 새 결과/골드를 메모리의 dirty 상태에 함께 남긴다. 발표창에 오류·저장 재시도·파일 내보내기를 제공한다. 재시도는 같은 결과를 쓴다.
- 미확인 최신 결과는 다음 실행에서 최종 상태로 다시 연다. 확인 상태 저장이 실패해도 다시 보기가 추가 보상을 만들지 않는다. 과거 결과는 당시 점수/금액을 읽는다.
- 기사 창에서 발표창으로 교체할 때 옛 기사 DOM 렌더를 종료한다. 시트 하나만 활성화하고 월드 입력을 잠근다. 닫으면 안정적인 수첩 HUD 버튼으로 포커스를 복구한다. 타이머/RAF/전역 이벤트/구독은 창을 닫을 때 정리한다.
