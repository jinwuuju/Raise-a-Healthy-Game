# 첫 출근 거리와 이동 조작감

D033 UI 변경: 아래 화면 방향 버튼8px/홀드 실험은 이전 표본이다. 현재 기본 HUD는 방향 버튼을 제거하고 클릭/터치 이동과 PC 키보드를 사용한다. [현재 HUD 원칙](../design/15-HUD-AND-MOBILE-UX.md)이 우선한다.

2026-10-10 · foundation-3 · 사용자 지정 범위: 현대 서울의 유로프라자에서 시작, 내부는 사진을 받기 전까지 임시, 주변 거리와 비투비씨 카페, 움직임 우선. 추가 상점은 이번에 구현하지 않는다.

## 장소 관찰과 표현

회사 시작은 **서울 강남구 논현로 805 유로프라자 안 편집국**이다. [입점사 공식 안내](https://www.ezmedicom.com/company/intro/location)는 압구정역4번 출구에서 논현동 방향500m로 설명한다. 지도 검색의 같은 건물 입점 장소는621m로 표시하여 정확한 실측 거리라고 단정하지 않았다.

[사용자 제공 카카오 로드뷰](https://kko.to/ZoCbLlDRfq)를 실제로 열어 마우스로 정면→오른쪽 도로→맞은편 상가를 돌려 보고, 도로의 다음 지점으로도 이동했다. 관찰 사진은2026년6월/7월 촬영분이다. 전면의 논현로159길,30표기·횡단보도·좁은 길, 옆의 큰 논현로·중앙 볼라드·가로수·차량, 맞은편 상가/호텔/주차 동선을 확인했다. 지도 사진을 게임 배경에 그대로 붙이지 않았다.

카카오 검색에서 [아토앤조이](https://place.map.kakao.com/1724306729)의 도산대로25길19를 확인하고 해당 로드뷰를 열었다. 밝은 석재, 긴 검은 차양, 통유리와 오른쪽 출입구를 원본 픽셀 건물로 재구성했다. 현재 사진의 간판과 검색 장소명이 달라 실제 매장의 현재 영업을 판단하지 않는다. 게임 이름과 용도는 사용자가 정한 **비투비씨 카페**다.

현재 street는1280×1280논리px의 압축 배경 초안이며 공칭 반경 약200m 범위 모델이다. 주변 블록은 관찰된 도로 관계를 바탕으로 간략화했다. **반경300m 전체의 실제 개별 건물을 거의 동일하게 재현한 단계는 아니다.** [장소 기록 원본](../../data/locations/apgujeong-start.v0.1.json)에 확인/미확인 범위를 남겼다. 300m 배경은 후속 대조/확장 목표이며, 지금 없는 상점 이용 기능을 완료로 표시하지 않는다.

## 이동 원본과 수치

[움직임 원본](../../data/balance/movement.v0.1.json)을 코드가 읽는다. 수치를 바꿀 때 이 문서도 갱신하고 render_levels/check_design을 실행한다. 단위는 게임 논리 픽셀이고 실제 지리의 미터나 실제 사람의 속도와 같지 않다.

| 항목 | 현재 값 | 동작 |
|---|---:|---|
| 논리 타일 |32px|환경 그리드 기준|
| 최대 걷기 |112px/초|약3.5타일/초; 대각선 정규화|
| 가속 |70ms|짧고 빠르게 시작, 갑작스러운 한 프레임 점프 없음|
| 키 놓은 뒤 감속 |50ms|최대 속도에서 약2.8px 이내로 정지|
| 화면 버튼 짧은 클릭 |8px|¼타일을 실제 애니메이션으로 이동; 즉시 좌표 점프 아님|
| 버튼 길게 누르기 |140ms 후 연속 입력|누르고 있는 동안 이동, 밖에서 놓아도 pointer capture로 해제|
| 보행 사이클 |4방향 × 8단계|6px 이동마다 다음 프레임; 일부 같은 포즈 공유|
| 문 진입 반경 |12px|영역 밖에서 안으로 실제 이동할 때 자동 출입|
| 느린 프레임 상한 |50ms|최대5.6px 이동 요청, application에서4px 이하 충돌 하위 단계|

키보드 이동 거리는 누른 시간에 따른다.80ms 누름+놓기에서 약8px,1초 누름+놓기에서 약111px를 목표로 한다. 짧은 화면 버튼 연타는 이동 목표를 버퍼에 쌓고, 방향키 연속 입력은 해당 버퍼/클릭 경로를 취소한다. 이동에는 평균 속도 적분을 사용하여30/60/120/144Hz의 거리 차이를 검사한다.

발점에 플레이어 그림자와 깊이를 맞추고,4방향 각각 8단계 보행 사이클을 실제 이동 거리에 맞춰 재생한다. 정지하면 마지막 방향의 기본 포즈를 유지한다. 외형 합성기는 생성/월드/HUD에서 공유한다. 문은 실제 이동으로 진입하며 도착점은 다음 문의 영역 밖이다. 작은 발 영역으로 가구/건물/가로수와 충돌한다. 클릭 이동은16px길찾기 그리드에서 유효한 경로를 찾고 같은 application 이동 규칙을 사용한다. 큰 도로는 횡단보도 경로만 통과한다.

패널을 열거나 창 포커스를 잃으면 입력/이동 버퍼를 정리하여 조작이 남지 않게 한다. 가속·감속이 코드 검사에서 맞아도 실제 사용자의 조작감 승인은 별개다. 불편한 관성/속도/보폭은 다음 플레이 피드백으로 조정한다.

## 비투비씨 이용

[카페 수치 원본](../../data/balance/cafe.v0.1.json)의 게임용 가격 가설이며 실제 매장 가격이 아니다.

| 메뉴 | 가격 | 제한 |
|---|---:|---|
| 첫 방문 아메리카노 |0G|최초1회|
| 물 한 잔 |0G|재화 없이 이용 가능|
| 아메리카노 |20G|선택 구매|
| 카페라테 |25G|선택 구매|
| 따뜻한 차 |15G|선택 구매|

주문 카운터 접근→메뉴→주문과 잔액/완료키를 한 transaction으로 저장한다. 첫 무료 커피 중복과 부족 잔액은 차단한다. 창가에서 쉬기와 거리 복귀도 구현했다. 음료/쉬기는 XP·의학 숙련도·진행 권한을 주지 않는다. 기존Q001~Q010의100XP/100G 시작과총2,270G계획은 변경하지 않았다.

## 저장·검증·다음

schema2/foundation-2에 cafe필드를 추가했고 schema3/foundation-3에 외형과 소유 의상을 추가했다. 기존 schema1을 읽으면 진척과 외형을 보존하여 이행하고 첫 저장 시 `schema1-original`을 IndexedDB에 남긴다. 향후 다른 게임 버전 저장을 덮어쓰지 않는다.

숫자/원자성·브라우저 실제 경로 검사 결과는 [STATUS](STATUS.md)에 기록한다. 실제 키보드/터치 체감과 아트 승인,고도/계단,300m지리 정밀 대조,다른 브라우저/기기는 남아 있다. 카페/회사 내부는 사진 수령 후 교체한다. 추가 상점은 후속 사용자 지정 목록을 받은 뒤 구현한다.
