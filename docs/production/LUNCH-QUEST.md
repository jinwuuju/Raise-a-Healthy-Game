## 3. 하루 흐름

1. 당김 칩 10개 중 하나(모바일 2열, 48px 이상).
2. 배달앱식 후보 4장: 같은 칸 3장 + 다른 칸 1장(아무거나는 서로 다른 칸 4장). 4장 중 1장에 과장 홍보 문구. 아래에 ‘굶기’ 선택지.
3. 과장 신고(선택): 맞히면 보너스, 틀려도 감점 없이 해설. 과장 문구 메뉴를 그대로 골라도 된다.
4. 똑똑하게 시키기 옵션(국물 덜기·공기밥 반·소스 따로·채소 추가·음료는 물 등). 옵션별 수치 변화는 근거가 있는 것만 넣는다.
5. 확정 → 저장 → 픽셀 식탁 → 동료 한마디 → 선택 카드 → 도감 등록.
6. 그날 자정까지 HUD 현재 목표 자리에 ‘오늘 점심: 메뉴명’(굶은 날은 ‘오늘 점심: 건너뜀’). 누르면 카드가 열린다. 지난 기록·도감은 수첩 ‘동네·생활’ 탭 한 곳에만 두고 다른 곳은 바로가기만(D067).

## 4. 영양 표시

- 열량·나트륨·단백질·탄수화물·당류·지방·포화지방·식이섬유를 1인분 값과 1일 영양성분 기준치 대비 %로 보여 준다. 색으로 좋고 나쁨을 표시하지 않는다.
- 1인분 = DB 100g당 분석값 × DB 1인분 중량. DB에 1인분 중량이 없는 4개(마라탕·돈코츠라멘·팟타이·분짜)는 같은 DB 비슷한 음식의 분석 중량을 빌려 쓰고 ‘1인분 중량 추정’을 표시한다.
- D080 근거 단계(nutritionStatus): `analyzed` 분석 행 → `calculated` 비브랜드 산출 행(레시피 계산값, 기준량 100ml·1회 분량 ml, 탕수육·깐풍기·닭강정·보쌈·닭꼬치) → `borrowed` 같은 DB 비슷한 음식 값으로 대체(순살치킨←후라이드치킨, 꿔바로우←탕수육, 포케·사케동←회덮밥, 규동←불고기덮밥, 카드에 ‘대체 값’ 표시) → `none` 숫자 없음(타코·부리또·케밥·반미·마라샹궈·카츠동·텐동, 카드에 ‘식약처 DB에 값 없음’). 브랜드(수집) 행은 상표가 섞여 쓰지 않는다. 1인분 양이 100 이하이거나 없으면(핫도그·소막창구이·닭꼬치) 1인분 값을 만들지 않고 기준량당 값만 보여 준다. 대체·값 없음 메뉴를 실제 측정값처럼 보이게 하지 않는다.
- 같은 음식의 다른 분석이 있으면(otherAnalyses) 범위로 함께 보여 준다. 예: 우동 420~1,264kcal. 가게·조사마다 크게 다르다는 것 자체가 학습 내용이다.
- 카드에 출처(식약처 K-FIND 음식 DB, 식품코드)와 ‘실제 가게·양에 따라 다름’, ‘검수 전 모형’을 표시한다.

## 5. 픽셀 식탁·음식 그림

- 장소: 편집국 내 자리 책상. 봉투가 놓이고 → 뚜껑이 열리고 → 그릇·반찬이 하나씩 놓인다. 약 3초, ‘결과 바로 보기’, 동작 줄이기 시 완성 화면만. 고른 옵션이 식탁에 보인다(공기밥 반, 소스 종지, 채소 접시, 낮아진 국물).

공통 규칙(나머지 187개도 동일):
- 크기 32x32(16px 타일 2x2칸), 기준점(16,30), 반투명 바닥 그림자.
- 3/4 위에서 본 시점, 왼쪽 위 광원, 재질마다 4단계 색 경사. 음식은 그릇 테두리 위로 보이게 쌓아 한눈에 메뉴를 알아본다.
- 외곽선은 검정이 아닌 재질의 가장 어두운 색 1px(실루엣 전체). 겹치는 조각(치킨 조각·컵)은 조각별 외곽선으로 구분.
- 먹음직스러움: 소스·국물·달걀에 흰 하이라이트, 고명(파·고추·깨) 색 포인트, 통통한 비율. 3배 크기에서도 재료를 알아볼 수 있어야 한다.
- 뜨거운 음식은 외곽선 없는 반투명 흰 김, 찬 음식은 반짝임, 상온 음식은 효과 없음.
- 12색 이상, 불투명 칸 30~90%. 무늬는 시드 고정 난수로 매번 같은 결과.
- 메뉴마다 고유 그림. 그릇 종류를 공유해도 내용물·고명·배치가 달라야 하며, 가능하면 메뉴 고유 표지(냉면 얼음, 김밥 단면)를 하나 이상 둔다. 상표·글자·실제 가게 포장 금지.
- 자동 검사 tests/unit/food-art.test.ts: 실제 메뉴 id 연결, 크기, 채움·색 수, 같은 그림·색만 바꾼 그림(색 순위 색인 비교)·차이 15% 미만 쌍 금지, 렌더링 결정성. 사람의 미감 승인은 별도 게이트.
- 미리보기: node tools/render_food_preview.mjs → artifacts/food-v0/preview.png(기준 5종) + artifacts/food-v2/<당김>.png(D084).

### 특징 강조 원칙 (D084, 사용자 피드백)

- 사실적인 축소보다 ‘그 메뉴라고 바로 알아보는 표지’를 우선한다. 메뉴마다 주인공 표지 하나를 정해 6~12px 크기로 키우고 자기 외곽선을 준다. 2~3px 고명은 곁들이로만 쓴다.
- 주인공은 그릇 테두리 위로 튀어나와도 된다(솟은 뼈, 인삼, 세운 김, 젓가락으로 든 면, 꼬챙이, 서 있는 새우튀김). 실루엣이 달라지면 작게 봐도 구별된다.
- 표지 예: 갈비탕=세로로 솟은 갈빗대, 뼈해장국·감자탕=등뼈 무더기, 삼계탕=통닭+인삼, 라멘=차슈·반숙·세운 김, 우동=분홍 소용돌이 어묵, 짬뽕=홍합, 순두부=몽글 두부+노른자, 부대찌개=햄 네모·라면 사리·치즈 장, 아귀찜=콩나물 산, 게장=등딱지, 돈가스=하얀 단면 줄, 치즈돈가스=늘어나는 치즈, 핫도그=꼬챙이+케첩, 피자=조각·토핑 모양, 비빔밥=방사형 나물+달걀, 김치볶음밥=달걀프라이, 팥죽=새알, 전복죽=껍데기째 전복, 김밥류=가운데 속 색.
- 같은 가족(김밥·피자·짜장·죽·덮밥)은 그릇·배치·주인공을 서로 다르게 고른다. 자동 고유성 검사는 서로 다름만 보며 알아보기 쉬움은 사용자가 판정한다.
