# UI·조작·아트·오디오 가이드

2026-10-10 사용자 UI 수정은 [HUD·모바일 UX 원칙](15-HUD-AND-MOBILE-UX.md)이 우선한다. 아래의 큰 옆 패널/화면 방향 버튼 후보를 현재 기본 HUD로 해석하지 않는다.

## 화면 구조

| 화면 | 기본 정보 | 주요 행동 | 다른 화면으로 가는 길 |
|---|---|---|---|
| 편집국 | 내 캐릭터·현재 의뢰 한 줄·작은 자원 바 | 이동·대화·컴퓨터·책장 | 월드맵·기사·도감 |
| 월드맵 | 전신 실루엣·기관별 입문 상태 | 지역 선택·잠금 이유 보기 | 기관 허브 |
| 기관 탐험 | 캐릭터·관찰점·목표·귀환 | 조사·장치 조작 | 퍼즐·도해·편집국 |
| 학습 도해 | 실제 관계·용어·움직임 | 레이어·정지·비교 | 방금 관찰한 위치로 |
| 기사 편집 | 주장·근거·기전·한계 | 카드 배치·미리보기·발행 | 보상·편집국 |
| 도감 | 발견 순·검색·관련 개념 | 근거·도해·재탐사 | 관련 탐험 바로가기 |
| 경영 | 시설·직원·수입 원인 | 구매·배치·역할 지정 | 편집국 |
| 설정/저장 | 글자·소리·조작·저장 상태 | 조정·내보내기·불러오기 | 이전 위치 |

첫 화면에서 인간 남성·인간 여성·외계생명체와 기본 옷을 간단히 고른다. 기본값으로 바로 시작할 수 있고 이후 무료 변경 가능하다. 다음 화면은 편집국이다. 처음엔 현재 의뢰만 보이고 숙련도 전체 대시보드는 첫 기사 이후 자연스럽게 연다.

## 레이아웃·해상도

게임 논리 화면 후보 640×360, 타일 32px. 정수 배율과 letterbox를 우선하여 픽셀을 선명하게 유지한다. DOM 텍스트는 게임 캔버스의 픽셀 크기에 묶지 않는다. 월드는 전체 뷰포트, 작은 HUD는 오버레이로 표현한다. 자세한 정보는 메뉴/대화에서 열며 좁은 화면은 하단 시트로 표현한다. 모바일 세로 조작은 P5에서 별도 검증하며 출시 대상 확정 전에는 지원한다고 표시하지 않는다.

UI 글자 본문 16~18 CSS px, 사용자 확대 200%를 목표로 한다. 대사는 한 말풍선 2~3줄, 전문용어는 첫 등장에 짧은 풀이를 붙인다. 도감은 상세 설명을 읽고 싶을 때 열도록 하고 새 개념마다 강제 팝업을 띄우지 않는다.

## 조작과 접근성

이동 WASD/방향키, 조사 E/Enter, 닫기 Esc, 도감 J를 기본 후보로 두고 변경 가능하게 한다. 클릭 이동은 P3 이후 후보이며 첫 버전에서는 클릭 상호작용만 지원해 경로 찾기 비용을 줄일 수 있다. 드래그 퍼즐은 선택→이동 버튼→확정의 키보드 경로도 제공한다.

색만으로 경로를 구분하지 않는다. 화살표·선 무늬·텍스트·아이콘을 함께 쓴다. 움직임 줄이기, 흐름 재생 일시정지, 화면 흔들림 끄기, 음악/효과음 분리, 자막을 제공한다. 속도·정밀 조작을 개념 이해의 증거로 쓰지 않는다. 모달은 포커스 순서·닫기·복귀를 검증한다. 캔버스의 현재 목표와 관찰 목록을 DOM으로도 제공한다.

## 비주얼 언어

깊이감 있는 탑다운 사선 2.5D 픽셀아트. ‘16비트’는 미술 방향이지 하드웨어 제약이 아니다. 캐릭터 32×48px 후보, 타일 32×32px, 초반 4방향 이동. 테두리 두께·그림자 방향·명암 단계·색상 수를 자산 가이드에서 통일한다. 얼굴 표정은 실제 감정 읽기가 가능할 만큼 단순하고 분명하게 한다.

편집국: 크림·갈색·청록 포인트, 나무 책상·신문·작은 식물. 심장: 따뜻한 적갈색과 분홍, 고어 없이 동선이 읽히는 층. 폐: 밝은 청록·파랑과 부드러운 흐름. 신경: 어두운 남색 위 절제된 신호선. 면역: 정원·연락망 비유 후보, 싸우는 적군으로 단순화하지 않는다.

기관 비유가 해부 사실처럼 보이지 않게 실제 도해 보기 버튼과 ‘탐험을 위한 모형’ 설명을 둔다. 도해는 선명한 SVG/벡터 또는 고해상도 그림으로 제작하고 구조 이름·방향·축척 여부·출처를 검수한다. 생성 이미지의 라벨을 의학 근거로 쓰지 않는다.

## 자산 목록과 제작 순서

P1: 회색 타일·색 블록·임시 캐릭터. P2: 주인공3프리셋·편집장·안내 로봇·맵 3개·흐름 이펙트·신문. P3: 심장 타일 확장·상점 오브젝트·도감 도해. P5 이후: 계통마다 키 아트 1개→팔레트·실루엣 가이드→필수 타일→퍼즐 오브젝트→연출 순서.

파일명은 `region_object_action_direction_frame` 같은 일관된 규칙을 사용하고 asset manifest에 제작자·라이선스·원본 위치를 기록한다. 무료 서체라도 배포와 수정 권리를 확인한다. 최종 아트 전체를 생성하기 전에 기준 캐릭터와 타일 1세트를 비교 검토한다.

## 오디오

편집국은 잔잔한 작업 분위기, 탐험은 발견을 돕는 짧은 동기, 보상은 길지 않은 신문 발행 소리. 심장 박동을 공포·과도한 긴장 장치로 사용하지 않는다. 심박·신호 소리는 학습 단서가 될 수 있지만 동일 정보를 시각적으로도 제공한다. 음소거에서도 모든 임무가 가능해야 한다.

예산 초안: 수직 단면 음악 2곡·효과음 6개, 초반 알파 음악 3곡·효과음 20개. 반복 소리는 빈도 제한을 둔다. 첫 사용자 입력 후 오디오를 활성화하는 브라우저 정책을 P1에서 확인한다.

## v0.2 아트 우선순위

세부 규격·Y정렬·의상 레이어·가림·집 배치는 [2.5D 아트 제작 기준](14-2_5D-ART-PRODUCTION.md)이 우선한다. HUD에 현재 착용 외형과 집으로 귀환을 연결한다. 도감 기초정보/기사 가이드는 처음부터 접근 가능하며 실제 관찰 기록만 플레이로 쌓인다.
