# 게임의 원칙과 핵심 루프

> **핵심 원칙(사용자, 2026-10-25, D115):** 우리는 의사가 아니다. 이 게임이 키우는 능력은 정확히 알고 쉽게 전하는 것이다. 진단·치료 판단을 가르치지 않고, 몸의 원리와 근거를 정확히 이해해 독자에게 쉽고 과장 없이 전한다.

## 대상과 플레이 약속

우선 대상은 의학 전공지식이 없는 한국어 독자다. 읽기 수준은 청소년 이상을 가정하되 연령 등급은 출시 심의 전 확정하지 않는다. PC 브라우저·키보드/마우스를 우선 검증하고 터치도 동일 명령 체계로 설계한다. 한 세션은 10~20분, 중간 저장은 언제든 가능하게 한다. v0.1의 40~60시간 가설은 생활·전신 범위 증가에 따라 재산정한다. 현재 총 플레이 시간은 미측정이다.

플레이어에게 약속하는 것은 “나는 취재로 세상을 조금 더 이해하고, 내 편집국이 자란다”이다. 학교 시험을 통과해야 볼 수 있는 RPG도, 클릭 수가 전문성을 대신하는 방치 게임도 아니다.

## 세계관

작은 지역 언론사 ‘메디컬 데스크’에 입사한다. 탐사 장치 ‘바디스코프’는 실제 사람을 축소해서 들어가는 장치가 아니라 **인체 원리를 탐험 가능한 모형으로 재현하는 가상의 장치**다. 임상 장비나 실제 진단 도구처럼 표현하지 않는다. 과장된 지형은 도해로 되짚으며 실제 구조와 다른 부분을 명시한다.

편집장은 정답을 설명하는 교사가 아니라 다음 취재의 이유를 준다. 탐사 안내 로봇은 관찰 방법과 조작을 돕는다. 독자 NPC는 생활 속 궁금증을 보내고 기사 후일담으로 성장의 의미를 보여준다. 환자는 구경거리·적·벌점의 원인이 아니라 존중받는 가상 취재 대상이다.

## 한 세션의 루프

1. 편집국에서 짧은 의뢰를 받는다. “몸 곳곳으로 보낸 혈액은 어디로 돌아올까?”처럼 상황과 호기심으로 시작한다.
2. 월드 또는 기관 지역에서 직접 움직이며 2~3개 관찰을 수집한다.
3. 흐름이나 장치를 조작하고 결과를 본다. 실패는 바로 이전 안전 지점으로 돌아가 다시 관찰하는 기회다.
4. 근거 보드에서 관찰과 설명을 연결한다. 이해 확인은 방금 한 행동을 새로운 작은 상황에 적용하는 방식이다.
5. 편집국으로 돌아와 기사 구조를 완성한다. 출처와 표현의 한계가 있으면 좋은 기사로 인정한다.
6. 골드·기자 XP·분야 수행 기록·명성·업적을 받는다. 책상이나 독자 반응 등 눈에 보이는 변화가 생긴다.
7. 다음 의뢰 하나를 제시한다. 사용자가 종료해도 불이익 없이 이어진다.

짧은 루프: 20~60초마다 움직임·관찰·상호작용. 중간 루프: 5~12분마다 작은 임무 결과. 긴 루프: 45~90분마다 새로운 공간·직급 도전·기사 묶음. 시간은 목표이며 테스트로 수정한다.

## 플레이 원칙을 규칙으로 바꾸기

| 원칙 | 실제 규칙 | 실패 신호 |
|---|---|---|
| 먼저 재미 | 캐릭터 선택 후 30초 내 이동, 90초 내 의뢰 | 설명을 계속 닫기만 함 |
| 조작이 개념과 연결 | 조작 전 예상→변화 관찰→설명 | 정답 버튼 색만 외움 |
| 실패가 관찰 기회 | 무제한 재시도·단계별 힌트 | 돈/체력을 잃어 탐험 회피 |
| 내 선택이 남음 | 기사 제목·강조점·사무실 배치 | 모두 같은 화면으로 종료 |
| 전문성은 분야별 | 고레벨도 새 분야는 입문 경로 | 기자 Lv만으로 모든 문 개방 |
| 정직한 기사 | 모르는 점·한계도 기사 슬롯 | 과장 제목이 수익상 최선 |
| 지속 가능 | 콘텐츠 버전과 구조 검사 | 새 기관마다 저장 코드 수정 |

## 세 개의 핵심 축 (D071)

인체 탐험(정상 구조·작동 원리) → 질환 취재(같은 공간의 질환 상태 비교와 원인·검사·치료·예방 근거) → 기사 작성(독자 질문과 오해 바로잡기). 질환은 각 기관을 구현할 때 함께 만든다. [질환 아카데미](16-DISEASE-ACADEMY.md).

## 콘텐츠 우선순위

필수: 이동, 상호작용, 퀘스트, 관찰, 퍼즐, 구조화 기사, 보상, 저장, 명확한 다음 목표.
확장: 직원, 시설, 선택 취재, 도감 관계도, 다른 기관.
후순위: 계절 이벤트, 사용자 맵, 클라우드, 스트리밍 연동, 생생한 NPC 대화 생성.
제외: 서바이벌 전투, 가챠로 학습 해금, 광고 시청 필수, 출석 연속 보상 압박, 의학 정답을 돈으로 사기, 실제 환자 정보 입력.

## 성공 지표의 해석

접속 시간 증가만 성공으로 보지 않는다. 첫 기사 완수율, 길 찾기 막힘, 다시 탐험하고 싶은 이유, 며칠 후 새로운 상황에서 설명 가능한지를 함께 본다. 학습 효과는 별도 동의한 테스트에서 확인하며 클릭 수나 XP를 학습 효과라고 발표하지 않는다.

## v0.2 생활과 정보 접근

시작 시 남성·여성·외계인 프리셋과 기본 의상을 빠르게 선택한다. 개인 주거·옷가게·가구·동네 관계가 수입의 의미를 만든다. 의학·기사 가이드는 검수된 범위에서 레벨과 무관하게 찾아볼 수 있다. 의상·집을 샀다는 이유로 기자 능력이나 의학 정답을 보상하지 않는다.
