# 기자 레벨 99·분야 숙련도·이해 증거

> **D108(2026-10-19) 변경:** 직급 승진에 그 구간 기본 장 졸업이 더해지고, 분야 숙련도는 기본 졸업 = 4·심화 = 5~10이며, 심화 XP는 장기 기본 XP의 50% 이하. 이 문서와 다르면 [설계 19 기본·심화](19-BASIC-AND-ADVANCED.md)가 우선한다.

## 세 가지 다른 상태

| 상태 | 의미 | 올라가는 방식 | 자동으로 주지 않는 것 |
|---|---|---|---|
| 기자 Lv.1~99 | 전체 활동 경험 | 최초 취재·새 발견·기사·변형 과제의 XP | 분야 전문성, 승진 |
| 분야 숙련도 1~10 | 해당 계통 수행 단계 | 개념 적용 증거 묶음 | 다른 계통의 숙련도 |
| 개념 증거 | 무엇을 어디서 해보았는가 | 관찰·모형 조작·전이 과제 기록 | 의료 자격·현실 진단 능력 |

미입문은 내부 값 0, 사용자에게는 숫자 레벨 대신 ‘미입문’으로 표시한다. 첫 관찰 후 1이다. 분야 숙련도는 XP 파밍형 수치가 아니라 아래 수행 문턱을 넘을 때 올라간다.

## 기자 XP

경험치는 정수·누적값이다. 시작 Lv.1, 누적 0. L에서 L+1로 필요한 값 E(L):

- L=1~10: `100 + 50 × (L−1)`
- L=11~60: `600 + 80 × (L−11)`
- L=61~90: `4800 + 120 × (L−61)`
- L=91~98: `8600 + 200 × (L−91)`
- Lv.99: 다음 레벨 없음. 추가 활동은 취재 이력으로 남기되 숨은 Lv.100을 만들지 않는다.

[99행 수치 원본](../../data/balance/levels.v0.2.json)과 [읽기용 레벨 표](02A-LEVEL-CATALOG.md)가 기준이다. 누적 T(L)=이전 모든 E의 합. 저장에는 누적 XP와 적용 balanceVersion을 보존하고 레벨을 파생한다. 후속 밸런스 변경으로 이미 얻은 레벨을 낮추지 않는 이행 정책을 사용한다.

XP는 한 기사에만 몰아주지 않고 임무의 발견·적용·발행 체크포인트에 분배한다. Q001은 20/30/50=100XP. 레벨 경계를 넘는 XP는 버리지 않는다. 같은 콘텐츠의 새로고침·재발행·반복 완료는 최초 XP를 다시 지급하지 않는다. 고레벨 보상은 한 임무 1~2개 레벨 상당으로 설계하고 다음 구간 진입 전 전체 콘텐츠 XP 예산을 시뮬레이션한다.

## 직급과 해금

| 권장 구간 | 직급 목표 | 주된 취재 방식 | 다음 승진 조건 |
|---|---|---|---|
| 1~10 | 수습 기자 | 관찰·간단한 흐름 | Lv.10 + Q010 종합 기사 |
| 11~20 | 신입 기자 | 정상 기능 비교 | Lv.20 + 서로 다른 분야 적용 2건 |
| 21~30 | 일반 기자 | 원인–변화–결과 | Lv.30 + 기전 기사 3건 |
| 31~40 | 취재 기자 | 검사 의미·조건 | Lv.40 + 오해 교정 기사 |
| 41~50 | 선임 기자 | 다기관 협업 | Lv.50 + 복합 취재 2건 |
| 51~60 | 전문 기자 | 연구·치료 원리 | Lv.60 + 근거 비교 기획 |
| 61~70 | 수석 전문기자 | 불확실성·관계 | Lv.70 + 상충 근거 검토 |
| 71~80 | 탐사팀장 | 팀 기획·장기 조사 | Lv.80 + 다기관 기획전 |
| 81~90 | 의학 에디터 | 기사 검증·편집 | Lv.90 + 편집 심사 묶음 |
| 91~99 | 수석 의학 에디터 | 종합 프로젝트 | Lv.99 + 최종 기획으로 ‘메디컬 마스터’ 칭호 |

직급은 승진 미션 완료 후 유지된다. 표의 레벨 구간은 권장 배치라서 Lv.15 수습도 가능하다. 첫 승진은 **Q010 완료 시 Lv.10에서 신입 기자**, Lv.11을 기다리지 않는다. 이후도 경계 레벨에서 다음 직급으로 승진한다. 레벨 표의 직급은 자동 확정값이 아니라 목표다.

지역 입문은 관련 초대 취재 완료로 해금한다. 심화 구역은 `방문 허가 AND 선수개념 적용 증거`를 요구한다. 기자 레벨은 권장 난이도와 시설 해금에 주로 사용하고 학습 문턱을 대신하지 않는다. 부족한 개념은 버튼 하나로 연결되는 3~5분 보충 탐사로 얻는다. 잠금 사유는 항상 구체적으로 표시한다.

## 숙련도 1~10 공통 골격

| 단계 | 필요한 수행 | 증거 예시 |
|---|---|---|
| 1 | 기관과 역할을 발견 | 위치를 탐사 지도에 연결 |
| 2 | 주요 구조 관계 관찰 | 구조 둘 사이 흐름 추적 |
| 3 | 기본 기능 직접 조작 | 모형 정상 상태 복원 |
| 4 | 다른 배치에 원리 적용 | 처음 보는 경로 해결 |
| 5 | 정상 조절 과정 설명 | 입력 변화와 결과 연결 |
| 6 | 이상 변화의 기전 추적 | 원인과 결과 순서 재구성 |
| 7 | 관찰·검사 의미와 한계 구분 | 한 관찰만으로 단정하지 않기 |
| 8 | 다른 기관과 관계 적용 | 복합 기전 근거 지도 |
| 9 | 여러 근거 비교·한계 서술 | 상충 자료의 조건 구분 |
| 10 | 분야 종합 기사 + 새로운 변형 적용 | 해당 분야 최종 취재 |

기관에 맞게 구체 증거 ID를 정의한다. Q001~Q010 종료 시 심혈관 숙련도 목표는 4이며 10이 아니다. Lv.99에도 모든 분야 10을 강제하지 않는다. 최종 캠페인 기획에는 최소 3분야 숙련도 6 + 연구 해석 경로를 요구하는 초안이며, 임의로 특정 전공을 강요하지 않도록 대체 분야 조합을 제공한다.

## 이해 확인과 도움

관찰만 하면 discovered, 안내를 따라 적용하면 practiced, 다른 상황에 적용하면 demonstrated. 이 세 상태는 게임 내부 증거 수준이며 임상적 능력 판정이 아니다. 수행 기록에는 conceptVersion, taskVariant, hintTier, inputMode, completionId를 남긴다.

힌트 1: 관찰할 곳 강조. 힌트 2: 방향 또는 비교 대상 제시. 힌트 3: 해결 시연 후 별도 변형으로 다시 적용. 힌트를 썼다고 보상을 깎지 않는다. 단, 시연을 그대로 따라 한 결과는 practiced로 남기고 demonstrated로 위장하지 않는다. 키보드 대체 조작과 시간 제한 해제는 개념 힌트로 간주하지 않는다.

## 반복·추가 레벨·콘텐츠 부족 방지

- 최초 완료 XP 100%, 완전히 같은 반복 0%. 다른 검수된 변형은 별도 completionKey로 1회 지급.
- 재탐험은 수집·장식·기사 관점 변경으로 의미를 준다. 핵심 성장에 반복 수익을 요구하지 않는다.
- 단계 출시 레벨 상한은 10/30/60/99. 상한에서 사라진 XP를 나중에 무한 복구하지 않는다. 확장 시 시작 보정은 별도 명시한다.
- Lv.99 이후는 분야 도전·기획전·도감·장식 중심. 기자 레벨 증가가 필요하면 독립 확장 설계로 재검토한다.
- 120개 메인 취재가 98번 레벨업과 일대일일 필요는 없다. 여러 레벨에 걸치는 취재와 중간 XP를 사용한다. P5부터 구간별 필수 XP 대비 공급 XP 110~125%를 목표로 하고 선택 임무를 강제하지 않는 경로를 검증한다.
