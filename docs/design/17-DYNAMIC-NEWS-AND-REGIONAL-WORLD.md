# D076 · 특종·미스터리·돌발 제보와 전국 취재 월드 통합 설계

문서 상태: **기획/구현 지침만 확정** · 작성일: 2026-10-13 · 구현: **미착수** · 기존 게임 상태: Q001~Q005 구현(D077, Q005 심방세동 동반 포함), 다음 메인 Q006. 이 문서의 이벤트는 여전히 미구현.

## 0. 사용자 확정 범위 및 최상위 원칙

이번에 채택하는 것은 **① 특종 잭팟(기사 발행 보상 연출·수집), ② 의학 미스터리 사건(단서 추적), ⑥ 돌발 뉴스·비밀 제보(선택형 사건 발생)**이다. 기존 ⑦ ‘오늘의 점심’은 이미 독립적으로 기획됐으므로 병합하거나 덮어쓰지 않는다. 세계 지도와 동네 월드는 훗날 전국 8개 게임 권역으로 확장하며, 해당 지역으로 **직접 취재를 가는 탐사 RPG**다.

**가장 중요한 해금 규칙: 현재 진행 중인 인체 기관·계통·질환과 연결된 사건만 보여 준다.** 지금 심장을 배우고 있으면 특종, 미스터리, 돌발 제보 모두 심장·순환·현재 열린 질환 범위 안에서 발생한다. 심장을 다 배우지 않았는데 당뇨나 뇌·폐 질환을 무작위로 메인 퀘스트처럼 끼워 넣지 않는다. 미공개 주제는 맵의 '준비 중' 표시나 다음 장의 예고 한 줄까지, 수집·진단·보상형 학습으로 해금하지 않는다.

**전국/전 분야의 전역 랜덤 심화 취재는 마지막 구간**이다. 모든 의학 질환이라는 무한 집합을 완료했다는 주장이 아니라, 버전으로 고정한 **기본판 10계통·12허브·필수 질환 커버리지 명세의 입문 경로가 공개·검수·접근 가능**하고 Lv.99 캠페인·필요 수행 증거를 만족한 뒤 별도 심화 모드를 연다. 그때부터 승인된 기존 분야를 무작위로 교차 조합한 종합 기획 취재를 제공한다. 조건 미충족 시 절대로 전역 랜덤 풀을 열지 않는다.

본 문서는 **코드·데이터·게임 화면·배포 아티팩트를 수정하지 않는다**. 확률, 빈도, 수량, 지역 이름/지도는 설계 가설이며 사용자 플레이와 검수 전에는 확정 게임 밸런스가 아니다.

## 1. 왜 붙이는가: 현재 코어 루프에서 출발

기존 확정 흐름:
편집장/독자 의뢰 → 바디스코프/월드 이동 → 정상 구조 관찰 → (열린 경우) 질환 비교 → 근거·기전·한계 정리 → 기사 발행 → D066 독자 반응/XP·골드 → 수첩/다음 의뢰.

D076은 이 흐름 앞뒤에 세 갈래의 **선택형 재미**를 잇는다:
- **사건 진입:** 편집국 제보함·동네 NPC·자료관·현장 인터뷰·심장 탐사 기록에서 분야에 맞는 사건이 뜬다.
- **취재 중간:** 미스터리는 기존 기관 공간/지역 월드에서 관찰·인터뷰·서로 다른 자료를 검증하며 단서를 수집한다. 정답 클릭 퀴즈로 대체하지 않는다.
- **발행 후:** 기존 D066 결과를 바탕으로 특종 표지/기념품/도감 기록의 희귀 연출을 더한다. 재화나 XP 중복 지급을 만들지 않는다.
- **되돌아오는 이유:** 인물 후일담·해당 기관의 남은 비밀·새 지역 제보를 열되, 언제든 그만둬도 불이익이 없다.

주요 성공 경험은 '랜덤으로 골드를 받았다'가 아니라 **예측하지 못한 사건을 직접 밝혔고, 기사를 쓴 결과 신문·독자·편집국·지도에 흔적이 남는다**는 것이다. 다음 임무는 하나만 명확하게 강조하고 나머지는 수첩에 보관한다. 뉴스의 선정성/의학적 과장을 보상하지 않는다.

## 2. 3개의 이벤트 유형 (서로 다른 목적)

| 코드/계열 | 발단 | 플레이 고유성 | 결말·보상 성격 | 메인 진척 |
|---|---|---|---|---|
| JACKPOT / 특종 잭팟 | 기사 최초 발행·명시적 새 회차 | 이미 확정한 독자 반응 뒤에 희귀 신문 표지·특집 배경·기념품 연출 | **장식·수집·후일담** 중심, 기존 D066 현금 규칙 보존 | 메인 필수 아님 |
| MYSTERY / 의학 미스터리 | 현장 취재 중 모순된 제보/기록 | 단서 비교·관찰·자료 출처 확인·가설 검증·기사 작성 | 취재 파일·특집 기사·미스터리 도감 | 선택형, 원칙적으로 메인 독립 |

세 시스템은 **하나의 이벤트 계약/중복 배제**를 공유하지만 '기사 결과 하나에서 세 보상이 독립적으로 발행'되는 구조가 아니다. 같은 플레이 행동에 같은 골드를 세 번 주지 않는다. 사건 종류의 중첩도 1회차 1건만 활성 공지(메인 목표는 유지)한다.

### 2A. 특종 잭팟: 기사 발행 결과와 결합

- D066의 기존 독자 반응·응원금 규칙(일반 20~160G, 6%의 200~600G, 기사 재발행시 추가 XP 없음)은 그대로 유지한다. 새 명목의 골드 잭팟이나 반응 점수 품질 평가를 덧씌우지 않는다.
- **새로운 보상 축**은 화면/소장형: 보통 지면 → 희귀 표지 → 특별 화보 → 전설적 기념호 등의 시각적 **희귀도 제안**. 희귀도/확률은 보상 데이터로 버전 관리하고 확률형 선택이 개입하는 경우 게임 내 명시적으로 고지한다. 현재 비율은 미정.
- 예시 수집품: 심장 박동 신문 액자, 순환 특집 표지, 기자 책상 장식, 심장 탐사 기념 배지. 모두 현재 분야 태그가 있는 것만 노출. 장식이 취재 성공률·기사 진실성·임상 성과를 높이지 않는다.
- 희귀 보상은 **최초 취재/해당 이벤트 첫 완료와 연계한 별도 1회 수집 보상**을 우선 검토한다. 기존 재발행은 D066 골드와 새 무작위 독자 반응만 허용하고, 재발행 무한 반복으로 한정 희귀 소장품을 쌓는 구조는 금지한다.
- 중복 수집품은 누적 교환 조각 또는 도감 진척으로 변경 가능하되, 'n회 실패해야 얻는 것'을 강요하지 않는다. 특정 기념품을 정해진 취재 성과로 직접 얻는 비확률 경로를 둔다.
- 미수령 표시·세이브 복원·장면 재진입·Skip/Esc는 **동일한 저장 결과를 재표시**해야 하며 재추첨하지 않는다. D066 결과 영수증과 신규 장식 영수증을 충돌 없이 연결하되, 수정 시 새 schema 이행/원자성 테스트 필수.
- 결론: **특종의 연출은 확률적이어도 기사 내용·근거·독자의 실제 건강 정보는 결코 무작위로 만들지 않는다.** 실제 돈 결제/유료 티켓/광고 시청/시한 압박/손실 만회성 뽑기는 범위 밖.

### 2B. 미스터리: 플레이어가 기자로서 조사할 이유

한 사건의 기본 6막:
1. 편집국 제보: 독자가 궁금해하는 질문 또는 **서로 충돌하는 주장** 제시(사실/가설 구분).
2. 현장 출동: 이미 열린 월드의 장소로 이동해 NPC·기록·취재 동의 확인.
3. 바디스코프 연결: 현재 열린 기관 구조/질환 레이어의 **실제 관찰점** 2개 이상 조사.
4. 근거 보드: 자료의 출처·실험 조건·관찰과 추정을 구별하고 가능한 설명을 좁힌다.
5. 반례/검증: 다른 조건에서 다시 관찰하거나 같은 현상을 오해하게 만든 제보의 한계를 확인.
6. 팩트체크 특집 기사: 확인 사실·모르는 점·단순화 한계를 쓰고 사건의 후일담을 남긴다.

정답은 데이터/출처/검수로 정해진 교육적 결론이고, 무작위는 **어떤 사건이 나오는지/어느 인터뷰를 먼저 만나는지/장식·연출**뿐이다. 가상 환자의 증상만으로 특정 질환 진단/처방·개인별 위험 계산을 강요하지 않는다. 실제 진단적 수치/응급 행동 지침은 해당 버전의 전문가 검수 전 공개하지 않는다. 막히면 힌트·취재 자료 다시 보기·안전 귀환을 무료로 제공한다.

기존 Q003 정상/협착/역류 비교, Q004 두 순환 노선과 연결되며, 신규 미스터리가 기존 메인 퀘스트의 근거를 **소급 완성하거나 무단 변경하지 않는다**. 해명 없는 허위 제보로 공포만 조장하지 않는다.

### 2C. 돌발 뉴스·비밀 제보: 오늘의 현재 분야만

- 표시 장소: 편집국 제보함(기본), 취재수첩 '지금 할 일'의 작은 배지, 열린 거리/카페 NPC의 말풍선, 월드 지도 현장 핀. **새 상시 전체 화면 팝업 금지**.
- 트리거: (a) 관련 메인 기사 1건 완료, (b) 기관 구조 최초 발견, (c) 취재 인터뷰 종료, (d) 지역에 실제 진입, (e) 하나의 사건 후일담 완료. '몇 분마다 무조건 생성'하지 않는다.
- 사건에는 짧은 속보형/후속 보도형/장기 비밀제보형이 있다. 제보는 승인된 스크립트/자료/퍼즐 ID를 가리키며 실제 인물·의료기관을 근거 없이 악역으로 묘사하지 않는다.
- 플레이어는 **지금 취재 / 수첩에 보관 / 관심 없음**을 선택한다. 무시·취소해도 명성/XP 감소·잃어버린 인체 지식·잠긴 메인 스토리가 없어야 한다.
- 이벤트는 기사 편집·심장 진입 연출·저장 복구·다른 대화창·모바일 강제 팝업 중에는 끼어들지 않는다. 중복 알림을 묶는다.
- 게임 접속 중 강제 타이머/자정 마감이 아니라 **완료한 메인 진행에 묶인 기회**로 제공한다. 한 회차에 여러 사건이 가능해도 활성 목록에 노출할 추천은 1건만.
- 세이브 파일을 삭제하거나 날짜/시각을 바꿔 유리한 희귀 보상을 강요하는 구조 금지. D068~D070 '오늘의 점심' 실제 00:00~11:30 규칙과 별도의 시계·대기 요구를 만들지 않는다.

- '모든 인체/질환 개방'은 **실제 우주 전체 의학지식**이 아니라 데이터 manifest 버전에 정의된 커버리지 달성이다. manifest에 각 허브·질환의 입문/검수/공개 상태, 선수 개념과 최소 취재 증거를 둔다. 나중에 콘텐츠를 추가해도 이미 열린 심화 상태를 불합리하게 되돌리지 않는다.
- 열람은 별개: 검수된 기본 정보는 Lv.1부터 검색 가능하다는 기존 원칙 유지. **랜덤 취재의 출현/실행**만 현재 허브·질환 게이트로 제한한다.
- 허브 이동 도중, Q005 같은 미완료 의뢰가 남아 있을 때 새 허브의 속보가 진행 필수처럼 표시되면 실패다.
- 범위 밖 제보는 선택 후보에서 제외한다. 후보가 0개면 **아무것도 발생하지 않는 것**이 올바른 결과다. 엉뚱한 타 분야 사건으로 채우지 않는다.
- 캠페인 1회차에서 이미 끝낸 허브도 수첩에서 재방문 가능하며, 해당 주제의 선택 취재는 허용한다. 새 분야를 시작한 뒤 메인 HUD는 현재 분야만 강조한다.

### 3A. Q005~Q010 실제 적용 슬롯

| 현재 진척 | 선택형 사건 슬롯(제안) | 미스터리의 핵심 근거 | 별도 주의 |
|---|---|---|---|
| Q001~Q004 완료 | **두 순환 취재 후속 제보**: 심장 방·판막 자료를 재확인 | Q003의 정상/협착/역류 차이, Q004 두 노선 카드 | 원래 첫 완료 보상 재지급 금지 |
| Q005 전도 신호 취재 완료 후 | **박동 신호 제보**: 정상 전도와 교육용 불규칙 패턴의 차이 | 전도 순서, 해당 질환 초안/의학 검수 범위 | 불규칙 신호 하나로 개인 부정맥 진단 금지 |
| Q006 심근 공급 취재 이후 | **심장에 피를 보내는 길**: 공급 구조와 조건 차이 | 관상혈류 관찰·출처 카드 | 협심증/경색은 해당 심화 게이트 전 미해금 |
| Q007 통로 조건 비교 완료 후 | **혈관 벽 사건**: 죽상동맥경화 기초의 병태생리 | 정상 혈관과 병변 레이어, 동맥경화 용어 구분 | Q004만 끝나도 Q007 정답 노출 금지 |
| Q008 혈압 취재 완료 후 | **측정값의 수수께끼**: 측정 조건·반복 측정의 차이 | 원인/위험요인, 측정과 해석의 한계 | 환자 특정 고혈압 진단·투약 판정 금지 |
| Q009~Q010 이후 | **심장 지역 특별호**: 이미 배운 사실 연결 | 2~3개 기존 심장 관찰·기사 | 미해금 뇌·당뇨 취재를 조기 강제하지 않음 |

위 슬롯은 모두 **설계만** 한다. 현재 메인 Q001~Q004는 완성·배포 상태 그대로 보존하며 다음 구현 순서는 Q005다. 플레이어에게 실제 이벤트가 출현한다고 표시하지 않는다.

## 4. 전국 팔도 취재 월드: 기존 동네를 확장하는 방식

전국은 기존 '편집국 → 서울 거리/카페 → 바디스코프'에서 **현장 취재 출동**을 더하는 방향으로 확장한다. 새로운 전국 화면이 인체 내부 탐사와 기사 작성 엔진을 대체하지 않는다.

- 3층 구조: **A. 전국 광역 지도(권역 선택) → B. 지역 동네/현장 맵(이동·NPC·취재처·증거 획득) → C. 바디스코프(관련 인체 기관·질환 레이어 탐험)** → 편집국 귀환·발행.
- 초기 거점은 현재 서울 편집국으로 고정. 가장 먼저 서울/수도권의 **실제 열린 동네 장소** 1~2곳에서 사건 표본을 검증한 뒤 지역을 하나씩 늘린다. 지역 추가가 질환 입문 순서를 앞당기지 않는다.
- **여덟 게임 권역 후보** (현대 지리를 위한 제작 단위이며 역사적 조선 팔도/현재 행정구역과 1:1 동일하다고 주장하지 않음): ①서울·경기·인천 ②강원 ③충청권 ④전북 ⑤전남·광주 ⑥경북·대구 ⑦경남·부산·울산 ⑧제주. 실제 방문 지역·지명·출입 동선은 현장 조사 후 확정한다. '전국 팔도'는 서사적 호칭이며 역사·행정 사실을 오인시키지 않도록 지도 범례에 명시한다.
- 지역별 '질환 발생 편견' 금지: 특정 지역이 고혈압/암이 많다는 등 실제 역학 주장은 공신력 있는 자료·검수 없이 만들지 않는다. 지역마다 **사람·제보 경로·공간 구조·취재 활동**이 다를 뿐, 질환은 허브 게이트가 결정한다.
- 각 권역의 최소 구성(후보): 출입/복귀 1, 취재 허브 1, 인터뷰 NPC 2~3, 관찰 포인트 2, 비밀 제보 1, 지역 후일담 1. 건물·개별 상점 실명 및 외관·상표·환자 정보는 별도 권리·사생활 검토.
- 현재의 논현로 거리/카페·횡단보도·집·옷가게 계획과 충돌하지 않는다. 전국 이동은 나중에 지도/역/교통 인터페이스로 구현하며 플레이어 실시간 장거리 이동을 강요하지 않는다. 필수 취재 여행 비용 0G, 무료 귀환·재개 보장.
- 지도에는 **이미 방문/취재 가능/주제는 알지만 미해금/미제작**을 구별한다. 지역 NPC 대사를 생성형 AI가 마음대로 의학정보로 채우지 않게 한다.
- 이벤트는 지역 ID와 허브 ID를 **모두** 가진다. '강원권에 갔다'는 이유만으로 미해금 호흡기 질환 사건을 발생시키지 않는다. 전국에 다 열려도 GLOBAL_DEEP_REPORTING 전에는 현재 허브 게이트를 우선한다.

### 4A. 전국 현장 취재의 차별화(모든 지역이 같은 인터뷰 2번이 아니게)

공유 동작은 대화·단서 수집·자료 검증·바디스코프 탐사·기사 발행이다. 현장마다 하나는 새로운 **환경 활용**을 둔다: 도서관에서 연구 버전 비교, 지역 축제의 잘못된 건강 주장 확인, 기자회견의 표·그래프 오류 찾기, 편집국 제보 창구의 증언 대조, 캠페인 포스터의 과장 표현 수정 등. 사실관계는 검수된 자료로만 확정한다. 지역 콘텐츠가 한국 관광 소개에만 그치지 않고 의료 기사 취재 과업을 달성하게 한다.

## 5. 사건 데이터 계약: 개발 전 고정할 최소 필드

다음은 **후속 데이터 스키마 설계 요구사항**이며 현재 파일 생성/구현 지시가 아니다.

| 구분 | 필수 계약 |
|---|---|
| 식별 | eventId(영구·유일), schemaVersion, contentVersion, locale, eventType(JACKPOT/MYSTERY/BREAKING), status |
| 소속 | hubIds, bodyPartIds, diseaseIds, campaignQuestIds, regionIds, stageScope, mainQuestBoundary |
| 접근 | prerequisites(직접 완료키·관찰 증거·허브/질환 공개 상태), minimumReviewState, allowedPhases, excludedDuring |
| 사건 | premise, authoredClueIds, observationIds, npcIds, locationIds, interactions, articleRubricId, sourceIds, simplificationNotes |
| 선택 | triggerEvent, weight/rarityVersion, cooldownPolicy, optional/skip/retainPolicy, poolVersion, onceKey |
| 지급 | rewardLedgerKey, rewardKinds, repeatPolicy, idempotencyKey, originArticleReceiptId, independentFromD066Gold |
| 저장 | eventInstanceId, selectedSeed, offeredAt, acceptedAt, state, evidence, rewardReceipt, version, migrationPolicy |
| 검수 | medicalReview, narrativeReview, locationRightsReview, QA status; 미승인 자동 풀 제외 |

**반드시 지킬 불변식**:
1. 사건이 뜬 뒤 새로고침해도 같은 사건·단서·희귀도·골드/기념품 결과. 재입장 재추첨 금지.
2. 이벤트 자산·질환 자료가 삭제/withdrawn 되면 기존 플레이의 핵심 취재 기록은 보존하고 이벤트만 보류·대체 경로 안내.
3. 한 보상의 논리적 지급 키는 1개. 결과창 재열기/애니메이션 스킵/중복 클릭/두 탭/저장 실패/옛 세이브에서 2회 지급 불가.
4. 임상적 사실·정답·환자 위험·검사 판정은 무작위 생성하지 않는다. 무작위는 승인 이벤트 선택/출현 순서/소장품·연출 등 비의료 정보에 한정.
5. 필수 메인 취재, 정보 접근, 무료 귀환을 이벤트 참여·희귀 보상·골드 운에 묶지 않는다.
6. 월드 사건은 이미 확정된 사건 데이터만 렌더링한다. 렌더·타이머·축하 연출이 도메인 진척을 직접 변경하지 않는다.

### 5A. 이벤트 상태 기계 (초안)

INELIGIBLE → ELIGIBLE → OFFERED → (PINNED / ACCEPTED / DISMISSED) → INVESTIGATING → READY_TO_PUBLISH → RESOLVED → ARCHIVED.

- 사건의 의학 콘텐츠가 보류될 경우 PAUSED_REVIEW 상태를 통해 실행하지 못하게 하되 기존 기록은 보존.
- 제보 무시 DISMISSED는 보상/명성 벌칙 없음. 반복 후보 복귀는 사용자가 선택한 재등장 정책에 한정.
- 저장 버전 변경 시 누락 필드는 빈 이벤트 상태로 이행하고 옛 Q001~Q004, 독자 반응, 수첩 기록은 유지. 신규 이벤트를 과거 완료 기록에 소급 완료로 만들지 않음.
- 보상은 (기사 발행/사건 완료 + 영수증 + 상태)가 application 단일 확정 경계. UI는 읽기만.

## 6. 랜덤 후보 선정 규칙(결정론적 재현)

1. 이번 세이브의 mainQuest/currentHub/currentDiseaseGate와 마지막으로 승인된 manifest 버전을 읽는다.
2. 후보는 published·의학/내러티브 검수 완료, region 접근 가능, 관련 학습 증거 충족, 해당 stageScope, 현재 허브 일치, 중복/쿨다운 통과한 사건만 남긴다.
3. 이미 진행 중 사건이 있거나 메인 대화/모달/장기 진입/저장 실패 복구/선택지 표시 중이면 **발생 연기**한다.
4. 후보를 안정 ID 순으로 정렬한 뒤 **저장된 회차 시드와 버전 고정된 가중치**로 최대 1개를 정한다. 후보 0개는 사건 0개.
5. 선택 즉시 eventInstanceId·poolVersion·selectionSeed·후보 ID·출현 결과를 원자 저장한다. 재실행/오프라인/장치 시간 변경에 결과 유지.
6. 선택된 사건이 현장의 퀘스트와 겹치면 제보함/수첩으로 접어두되 메인 HUD 목표를 덮지 않는다.
7. 전역 심화 단계는 분야별 과다 반복 방지 가중치와 플레이어가 보유한 승인된 수행 증거를 함께 확인한다. **의학 출처가 없는 무한 즉석 사건 생성 금지**.

초기 발생 빈도와 확률은 실측 전에 확정하지 않는다. **시험 가설**은 '메인 퀘스트 1~2개 완료 뒤 관련 부가제보 0~1개 추천', '짧은 사건 3~8분', '미스터리 8~15분', '다음 사건이 자동으로 보장된다고 말하지 않기'다. 희귀 아이템 확률/피로도/반복률·후속 반응을 5명 이상 사용성 관찰 및 반복 플레이 시뮬레이션으로 조정한다.

## 7. 진행 예시: 심장 Q005~Q008, 그다음 전국

### 예시 A: Q005 '의문의 박동'

- 편집국에서 Q005 의뢰를 **정상 루트대로** 받는다. 전도계 관찰을 시작하기 전에는 부정맥 미스터리를 후보에 넣지 않는다.
- Q005의 전도 신호 비교에 필요한 관찰을 수행하면 수첩 제보함에 '박동 신호와 관련한 기록이 들어왔다'가 선택적으로 나타난다.
- 플레이어가 수락하면 **이미 열린 심장 방에서** 신호 시간 차를 관찰하고 기자용 자료의 오류를 찾는다. 처음에는 정상 설명 범위; 승인된 질환 비교 레이어는 Q005에서 열릴 때에만 사용.
- 기사 발행 후 D066의 독자 반응은 기존대로. 별도 기념 심전도 그래픽 '수집품'은 의료 판독 결과가 아니라고 표시.
- 미스터리를 하지 않아도 Q005 필수 1회 보상, Q006 입장, 골드 0 진행을 보장한다.

### 예시 B: Q008 고혈압의 '서로 다른 측정 결과'

- Q008 혈압 정상 조절·측정 조건 학습을 끝낸 경우에만 등장하는 비밀 제보.
- 게임 자료에서 측정 자세·시간·반복성의 조건을 대조하고, 개인에게 진단을 내리는 대신 **측정값의 해석 한계**를 기사로 정리한다.
- 돌발 독자 질문은 지역 제보함에서 들어올 수 있지만 취재 자체는 기존 심혈관 허브의 학습 진척에 묶인다.

### 예시 C: 전국 취재에 나가는 고레벨 기자

- 서울 편집국에서 광역 지도의 공개된 권역으로 이동 → 지역 기자/시민 제보 청취 → 현장 기록 확보 → 바디스코프의 현재 열려 있는 허브 재탐험 → 자료 팩트체크 → 서울 또는 지역 임시 편집 자리에서 발행.
- 모든 입문 커버리지가 승인되기 전에는 지역만 넓힐 뿐 **교육 분야는 현재 열린 범위**에서 시작한다.
- 최종 심화 모드 진입 뒤에만 '강원권 제보 + 심혈관/신장/내분비 연계' 등 **검수한 교차 분야 취재 묶음**이 랜덤 후보에 들어간다.

## 8. 기존 시스템 보호·충돌 해결

| 기존 기능 | D076과의 관계 |
|---|---|
