# 22. 바디스코프 3D 외형 모형 (D118)

2026-10-29 · 사용자 결정(11:05~11:15): ‘바디스코프에 학습 3D 모형도 하나 만들자. 지금은 장기 하나로 들어가는데, 전체를 3D로 보면서 마우스나 터치로 돌려 가며 구조를 확인할 수 있게. 들어가는 건 내부고 이건 외형. 인체 지도에서 자세히 보기를 누르면 3D 모형이 나오고, 중요 위치나 구조를 누르면 팝업으로 설명이 뜨게.’ ‘너무 단순하면 별로니 로딩이 길어져도 어느 정도 정교하게.’

## 1. 무엇인가

- **안과 밖의 짝:** 장기 속 방(심장 6개, 호흡기 6개)은 안에서 걷는 곳이고, 이 모형은 같은 몸을 **바깥에서** 돌려 보는 곳이다. 내부 탐험을 대신하지 않는다(D072 ‘바깥 연출이 내부 탐험을 대신하지 않는다’와 같은 원칙).
- **여는 곳:** 편집국 바디스코프 선택지 ‘3D 외형 모형 보기’(들어가기 전에), 바디스코프 지도의 인체·심장·호흡기 축척에서 ‘자세히 보기 · 3D 외형 모형’. 지도에서 열었으면 ‘바디스코프 지도로 돌아가기’로 돌아간다.
- **조작:** 끌어서 돌리기, 휠·두 손가락으로 확대, 오른쪽 버튼·두 손가락으로 옮기기. 같은 일을 버튼으로도 한다(왼쪽·오른쪽·위·아래로 돌리기, 확대·축소, 앞·뒤에서 보기, 처음 시점). 동작 줄이기 설정이면 시점 이동 애니메이션을 하지 않는다.
- **설명:** ‘구조 목록’에서 고르거나 모형의 구조를 직접 누르면 설명 칸에 이름·쉬운 설명·근거가 뜨고, **그 구조 하나에만** 위치 표시(깜빡이는 금색 점과 이름표)가 생긴다. 목록에서 고르면 시점이 그 구조로 간다. 항상 떠 있는 점은 두지 않는다(사용자 피드백 2026-10-29 13:33: 점이 많아 정신없고 모형이 잘 안 보임). 가려진 위치는 흐리게 보인다. 끄는 동작과 누르는 동작을 구분한다(움직임 6px 이상이면 돌리기).
- **읽기 전용:** 저장·XP·골드·탐험 기록을 바꾸지 않는다. 학습 보조 화면이다.

## 2. 보는 범위와 층

| 범위 | 기본으로 보이는 층 | 설명 점 |
|---|---|---|
| 전신 | 몸 윤곽(반투명)·뼈대·심장과 혈관·폐·기도와 식도·횡격막 | 심장, 좌우 폐, 기관, 갑상연골, 횡격막, 갈비뼈·가슴뼈·척추 |
| 가슴 속 | 몸 윤곽만 끔 | 심장·큰 혈관, 폐, 기관·식도, 횡격막, 뼈대 |
| 심장 | 심장과 혈관만 | 네 방, 심첨, 심방귀, 대동맥(오름·활·내림)과 활의 세 가지, 폐동맥줄기, 위·아래대정맥, 폐정맥, 오른관상동맥·앞심실사이가지·휘돌이가지 |
| 호흡기 | 심장과 혈관·폐·기도·횡격막 | 코안·코선반·인두·후두덮개·갑상연골·반지연골·기관·C자 연골 고리·식도·기관용골·좌우 주기관지·기관지 나무·좌우 폐·엽 사이 틈새·폐문·폐 속 혈관 가지·폐첨·심장 패임·횡격막 |

층 버튼(몸 윤곽·뼈대·심장·혈관·폐·기도·식도·횡격막)으로 언제든 켜고 끈다. 층을 끄면 그 층의 점도 숨는다.

**호흡기가 열리기 전(심장 졸업 전):** 기도·폐·횡격막은 회색으로만 그리고 설명이 없다. ‘호흡기’ 범위 버튼은 잠기고, 그 자리를 누르면 ‘심장 졸업 특집호를 발행하면 열려요’를 보여 준다(설계 19·20의 장 순서, AGENTS 6절 ‘아직 열리지 않은 기관은 준비 중’).

## 3. 정교함: 모양을 숫자로 만든다

외부 이미지·3D 파일 없이 코드로 만든다(D037의 ‘외부 그래픽 0장’ 원칙을 3D에도 적용). 센티미터 좌표(x = 사람의 왼쪽, y = 위, z = 앞)로 해부 관계를 적고, 부드러운 형상(부호 거리장, smooth union)을 표면망(surface nets)으로 메시화한다. 처음 열 때 몇 초 동안 만든다(사용자 허용).

- **심장:** 좌우 심실·심방·심방귀 타원체를 홈이 남게 이어 붙인다. 긴 축은 바닥(오른쪽 뒤 위)에서 심첨(왼쪽 아래 앞)으로. 방마다 색을 조금 달리 칠한다. 관상동맥은 **모형 위에서 홈을 찾아** 놓는다: 앞심실사이가지는 두 심실이 같은 거리로 만나는 앞면 선, 오른관상동맥·휘돌이가지는 심방과 심실 사이 고리 홈. 홈의 지방(옅은 노랑)과 큰심장정맥도 그린다.
- **큰 혈관:** 오름대동맥 → 대동맥활(세 가지: 팔머리동맥·왼온목동맥·왼빗장밑동맥, 오른쪽부터) → 내림대동맥, 폐동맥줄기(대동맥 앞) → 좌우 폐동맥(오른쪽은 오름대동맥 뒤), 위대정맥과 좌우 팔머리정맥, 아래대정맥, 좌우 두 개씩 폐정맥. 색은 산소가 많은 피 = 붉은색, 적은 피 = 파란색이라는 **구분용 약속**임을 화면에 밝힌다.
- **기도:** 코안(가운데 벽과 세 겹 코선반), 인두, 갑상연골 두 판·반지연골(뒤가 높은 반지)·후두덮개·목뿔뼈, 기관과 뒤가 열린 C자 연골 고리 18개, 식도(기관 바로 뒤), 기관용골, 오른주기관지(짧고 굵고 곧게)·왼주기관지(길고 비스듬히, 대동맥활 아래), 엽기관지(오른쪽 셋, 왼쪽 둘과 혀구역), 그 아래는 엽 안의 표본점을 향해 둘씩 갈라지는 **기관지 나무**(분기마다 반지름 약 0.79배, Murray 법칙; 고정 시드라 모든 기기에서 같은 모양).
- **폐:** 아래는 횡격막 돔에 맞춰 오목하게, 안쪽은 세로막 쪽으로 평평하게, 심장 자리는 파내고 왼폐에는 심장 패임을 둔다. 오른폐가 더 크고 넓고 짧다. 빗틈새·수평틈새로 엽을 나눠 엽마다 색을 다르게 칠하고 틈새는 진한 선으로 보인다. 반투명이라 속의 기관지 나무와 폐동맥·폐정맥 가지(기관지를 따라)가 비친다.
- **횡격막:** 두 돔(오른쪽이 조금 높음)과 심장이 얹힌 중심 힘줄(옅은 색).
- **뼈대:** 갈비뼈 12쌍(1~7번은 연골로 가슴뼈에, 8~10번은 위 연골 쪽으로, 11~12번은 뜬갈비뼈), 가슴뼈(손잡이·몸통·칼돌기), 빗장뼈, 목뼈 7·등뼈 12·허리뼈 5(몸통·고리·가시돌기·가로돌기).
- **몸 윤곽:** 머리·코·목·가슴·배·골반·팔·다리를 반투명 피부로.

## 4. 검증

- 단위(`tests/unit/body3d.test.ts`): 표면망이 닫힌 바깥 방향 메시인지(오일러 특성·부피), 심첨 방향과 방의 앞뒤·좌우 관계, 관상동맥이 홈 위에 있는지, 대동맥활이 왼주기관지 위를 지나고 세 가지가 활에서 오른쪽부터 나는지, 폐동맥줄기가 대동맥 앞·오른폐동맥이 오름대동맥 뒤인지, 오른주기관지가 짧고 굵고 곧은지, 기관이 식도 앞인지, 오른폐가 크고 넓고 짧으며 세 엽(왼폐 두 엽)인지, 심장 패임, 기관지 나무가 폐 안에서 가늘어지는지, 심장이 중심 힘줄 위에 있는지, 갈비뼈 12쌍과 뜬갈비뼈, 노드에서 GPU 없이 모든 층을 만드는지, C자 고리 뒤가 열려 있는지, 호흡기 전에는 호흡기 설명이 메시에 붙지 않는지, 본문 계약.
- 브라우저(`tests/e2e/body3d.spec.ts`): 바디스코프에서 열기, 범위 전환, 목록으로 설명 열기, 화면 가운데 누르기로 심장 구조 고르기, 끌어서 돌리기(끌기는 누르기가 아님), 뒤에서 보기, 층 끄면 점 숨김, 호흡기 설명, 지도에서 열고 돌아가기, 졸업 전 잠김, 390×844·844×390·1440×760에서 화면 밖·잘림·작은 버튼 없음.
- 설계 검사(`check_design`): 초안 표시·근거·숫자 금지·질환 이름 금지·범위와 층. 빌드 검사(`check_game_build`): three.js는 지연 청크에만, 그 청크는 ‘검수 전 모형’ 표시와 초안 상태를 지닌다.
