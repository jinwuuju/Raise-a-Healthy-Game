# 건강기자 아카데미와 언제든 쓰는 실무 가이드

## 기자가 배울 두 영역

인체 지식만으로 좋은 건강기사를 쓸 수는 없다. **의학 이해**와 **취재·근거·글쓰기·윤리**를 함께 성장시킨다. 기자 아카데미는 의학 분야 숙련도와 별도의 수행 배지이며 돈으로 살 수 없다. 가이드는 처음부터 검색 가능하고 실습은 캠페인 속 상황으로 경험한다.

## 10과목·40실습의 초안

| 과목 / 실습 수 | 실제로 연습할 내용 | 권장 구간 | 기사에서 남는 결과 |
|---|---|---|---|
| 뉴스 기획 / 4 | 독자 질문, 뉴스 가치, 범위 좁히기, 취재 계획 | 1~20 | 한 문장 기획서 |
| 기사 구조 / 4 | 제목·리드·본문·마무리, 역피라미드와 설명형 선택 | 1~30 | 읽히는 첫 기사 |
| 취재·인터뷰 / 4 | 질문 설계, 확인 질문, 인용 맥락, 녹취/기록 | 11~40 | 근거 있는 인용 |
| 출처 검증 / 4 | 원출처, 재인용, 전문성/이해충돌, 자료 날짜 | 21~50 | 출처 카드 |
| 연구 읽기 / 4 | 연구 질문, 대상, 설계, 결과/한계 | 31~70 | 논문 요약표 |
| 수치·위험 전달 / 4 | 분모, 절대/상대 차이, 불확실성, 그래프 | 41~80 | 오해 없는 수치 문장 |
| 인과·과장 검토 / 4 | 상관/인과, 과잉 일반화, 연구 단계, 과장 제목 | 41~90 | 팩트체크 메모 |
| 윤리·환자 이야기 / 4 | 동의, 사생활, 낙인, 광고/기사 구분 | 11~80 | 존중하는 서사 |
| 공중보건·보건의료 / 4 | 예방, 환경/사회 요인, 접근성, 정책 근거 | 51~99 | 개인과 사회를 잇는 기사 |
| 편집·정정·전달 / 4 | 교열, 도해 검토, 정정, 독자별 쉬운 설명 | 61~99 | 최종 특집호 |

40개 실습은 메인120/선택취재60 안에 포함한다. 별도로 40개의 필수 노가다를 추가하지 않는다. 초기에는 4실습만 제작: 독자 질문 정하기, 관찰과 설명 구분, 짧은 리드 만들기, 출처/한계 붙이기.

## 기사 작성 가이드: 실제 화면 흐름

1. 누구의 어떤 궁금증을 풀 것인지 정한다.
2. 지금 알고 있는 사실·추정·아직 모르는 점을 분리한다.
3. 자료의 작성 주체·날짜·대상·연구 설계와 원출처를 확인한다.
4. 취재에서 관찰한 것을 주장과 연결한다. 인용은 원래 맥락을 유지한다.
5. 핵심 메시지를 한 문장으로 쓰고 리드에 담는다.
6. 기전·자료·반론·한계로 본문을 구성한다.
7. 제목이 본문보다 강하게 단정하지 않는지 확인한다.
8. 숫자에 분모·기간·단위·비교 기준을 붙인다.
9. 의료정보가 개인에게 그대로 적용된다고 말하지 않는지 검토한다.
10. 출처·갱신일·필요한 정정 통로를 남기고 발행한다.

게임 UI는 처음에 3슬롯, 중반 4슬롯, 후반 6~8슬롯으로 확장한다. 항상 같은 양식을 강제하지 않고 설명기사·인터뷰·팩트체크·연구해설·현장기획을 선택한다. 자유 메모는 플레이어의 초안이며 검수된 정보로 재배포하거나 자동 정답 처리하지 않는다.

## 기사별 도구 상자

- 기획서: 독자, 질문, 뉴스 가치, 필요한 근거, 아직 모르는 것, 인터뷰 후보 역할.
- 인터뷰 노트: 질문, 발언, 맥락, 확인해야 할 사항, 공개 동의 범위(가상 취재).
- 논문 읽기: 대상/규모/기간, 설계, 비교, 결과, 한계, 자금/이해충돌, 적용 범위.
- 수치 점검: 분모, 단위, 기간, 절대 변화, 상대 변화, 불확실성, 그래프 축.
- 팩트체크: 원 주장, 원출처, 확인된 것, 확인되지 않은 것, 더 정확한 표현.
- 정정문: 무엇이 달라졌나, 왜 바꿨나, 독자 판단에 어떤 영향이 있나, 수정 날짜.

실제 의료 판단을 입력받지 않는 빈 양식으로 제공하고, 기자가 업무 공부에 참고할 수 있도록 인쇄/내보내기를 P4 이후 구현한다. 기사 템플릿 자체와 의료 주장 내용의 검수는 구분한다.

## 예시 실습

‘효과가 두 배’라는 제목 초안을 받은 플레이어가 표의 분모와 절대값 카드를 추가한다. 숫자는 명확히 가상 데이터로 라벨링한다. 정답 문장을 외우게 하기보다 무엇이 빠지면 독자가 오해하는지 비교하도록 한다. 실제 치료 효과처럼 보이는 수치를 검수 없이 넣지 않는다.

또 다른 실습은 주민 인터뷰 일부만 떼어 인용한 기사를 전체 발언 맥락에 맞게 수정하는 것이다. 기사 품질은 클릭수보다 정확성·이해 가능성·존중·한계 설명으로 피드백한다. 논쟁적 사안에서 근거 수준이 다른 두 주장을 자동으로 50:50 균형 처리하지 않는다.

## 질환 취재와의 연결 (D071)

출처 검증·연구 읽기·수치와 위험 전달·인과와 과장 검토·윤리와 환자 이야기 실습은 [질환 아카데미](16-DISEASE-ACADEMY.md)의 질환 취재 6단계 안에서 경험하게 한다. 질환 기사는 진단·치료 지시가 아니라 원리·근거·한계를 전달하는 설명기사·팩트체크·연구해설이다.

## 정보 범위 확장

기본 의학 외 영양·운동·수면·정신건강·약물/의료기기 정보 읽기·건강검진·예방접종·감염병 보도·고령화·장애와 접근성·보건정책·환경보건을 장기 취재 주제로 등록한다. 실제 권고·기준·법규는 판본/지역/날짜가 필요하므로 고정된 영구 정답 카드로 만들지 않는다.

도감에 모든 주제를 넣는 것보다 출처·단순화·갱신 가능한 구조가 우선이다. 검색 결과의 ‘미작성’은 솔직히 표시하고 게임 생성 모델이 빈 내용을 의학 사실로 채우지 않게 한다.

## 평가와 보상

실습마다 ‘발견한 문제→수정한 이유→다른 초안에 적용’ 3단계를 기록한다. 결과는 기자 배지와 기사 아카이브로 남긴다. 체크리스트를 열어본 횟수·단어 수·복붙 횟수는 전문성 점수가 아니다. 언어 표현의 다양성을 허용하되 의미 태그·필수 근거·과장 검토를 일관되게 적용한다.
