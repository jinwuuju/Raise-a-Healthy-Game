## 2026-10-10 / 실제 구현 착수

- D025 사용자 확정: 설계에서 실제 구현으로 전환하고 작업 큐 순서대로 진행. D004의 설계 전용 제한을 대체한다. P0 내부 탁상 검토를 기록한 뒤 의료 본문이 없는 P1 기반을 구현한다. 사용자 역할극·전문 검수·아트 승인 미실시를 완료로 바꾸지 않는다. P2 진입에는 남은 기반/콘텐츠/아트 조건을 따로 확인한다.
- D026 구현 선택: Node 24.19.0 / npm 12.2.0 / Phaser 4.2.1 / TypeScript 7.0.2 / Vite 8.3.4 / Vitest 5.0.3 / Playwright 1.64.0, exact dependencies와 lockfile. 초기 화면은 640×360 G0 편집국+임시 로비이며 원래 심장 맵 설계 크기를 변경하지 않는다. 캐릭터는 임시 기본3종과 이름만 선택한다. 실제 아트·확장 외형은 후속 제작.
- D027 구현 선택: Web Locks로 단일 쓰기 세션, IndexedDB revision 비교/원자 저장/정상 백업2개. 잠금 미지원은 읽기 전용. 조사/장면 전환 자동 저장, 이동은 명시적 위치 저장. P1 저장 schema 1 / foundation-1; P2 필드 추가 때 기존 원본 보존과 migrator 필요. 손상/미지원 저장 자동 덮어쓰기 금지.
- D028 구현 선택: Vite publicDir 비활성화, 런타임 자산은 명시적 import만 사용. 기존 runtime README를 자동 복사한 첫 빌드는 경계 검사에서 실패했으며 allowlist 방식으로 수정했다. 미검수 의학 예시·밸런스·카탈로그는 게임 빌드 제외. 공개 설계실 배포 구조는 유지하며 원격 게임 배포는 수행하지 않는다.

## 2026-10-10 / 사용자 시각·장소·조작감 수정

- D029 사용자 확정: 첫 게임 화면은 전체 픽셀 월드와 게임 HUD다. 웹페이지 형태의 소개/카드 레이아웃을 철회하고 Phaser 카메라·타일 질감·독립 오브젝트·발 y 정렬·가림·4방향 걷기로 구현한다. 참고 게임의 픽셀 공간감만 참고하고 자산/맵/UI를 복제하지 않는다. 배경 연도는2026년 현대 서울.
- D030 사용자 확정: 시작 회사는 서울 강남구 논현로805 유로프라자 내부. 회사 내부는 후속 사진까지 임시 배치. 카카오 로드뷰의2026년6/7월 사진을 직접 회전·이동하여 외관/도로를 관찰한다. 현재200m 공칭 압축 거리 초안,300m 유사 배경은 후속 대조 목표. 정확한 측량/모든 건물 완성으로 기록하지 않는다.
- D031 사용자 확정: 아토앤조이 위치 외관을 참고해 비투비씨 카페를 만들고 이용 가능하게 연결. 기존 큐의 상점/생활 전체를 완료시키지 않고 사용자 지정 P1-CAFE 표본만 먼저 구현한다. 게임 가격/무료 첫 방문/물/쉬기는 [수치 명세](../production/MOVEMENT-AND-STREET.md)를 따른다. Q001~Q010 보상/XP는 변경하지 않음. schema2/foundation-2/cafe-0.1, schema1 진척 보존 이행 및 원본 보관.
- D032 사용자 확정 및 구현 가설: 이동 조작감 우선.112px/초,70ms 가속/50ms 해제, 화면 버튼8px 짧은 애니메이션 이동/140ms 홀드, 대각선 정규화와4px 충돌 하위 단계. 값을 data/balance/movement.v0.1.json에서 관리하고 실제 체감에 따라 조정. 추가 상점은 이번 범위에서 제외.
